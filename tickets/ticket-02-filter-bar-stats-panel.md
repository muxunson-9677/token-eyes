# 工单2：顶部筛选栏 + 统计面板

## 基本信息

- **工单编号**: TICKET-02
- **标题**: 顶部筛选栏 + 统计面板
- **优先级**: 高
- **依赖**: 工单1（后端 API + 数据层）
- **可并行**: 工单3

## 对应需求点

- 需求1.1: Agent 切换图标 UI
- 需求1.2: Agent 切换全局数据范围
- 需求2.1: "全部来源"下拉筛选 UI
- 需求3.1: "全部模型"下拉筛选 UI
- 需求4.1: 时间快捷选项
- 需求4.2: 日历弹窗自定义日期时间
- 需求7.2: 三级筛选级联逻辑

## 项目背景

当前 Token Eye 的 Spend 页面筛选功能简单，只有日/周/月切换和 source 筛选。需要参考 CC Switch 的使用统计页面，实现一套完整的顶部筛选栏和统计面板，包括 Agent 切换、来源筛选、模型筛选、时间范围选择、刷新间隔，以及多维度的统计数据展示。

## 技术栈

- React + TypeScript
- Tailwind CSS
- 状态管理：使用工单1提供的 `useUsageFilters` Hook
- 数据：使用工单1提供的 `useUsageSummary` Hook

## 设计参考

视觉风格参考 CC Switch 使用统计页面：
- 顶部一排筛选控件，从左到右排列
- Agent 切换用图标按钮组
- 下拉筛选用胶囊形按钮
- 统计面板左侧大数字 + 4个维度卡片，右侧小统计卡片
- 整体风格简洁现代，圆角、阴影、白色卡片

### A. Agent 切换图标组

**组件**: `AgentSwitcher.jsx`
**路径**: `dashboard/src/ui/dashboard/components/AgentSwitcher.jsx`

#### 功能描述

顶部最左侧的 Agent 切换图标组，用于切换全局数据范围：显示全部 Agent 或只显示某个 Agent。

#### UI 细节

1. **按钮组排列**：水平排列的圆角按钮组，整体有圆角背景
2. **第一个按钮**：
   - 图标：网格/方块组合图标（表示"全部"）
   - 悬停效果：背景变深
   - 选中状态：白色背景 + 阴影
3. **后续按钮**：
   - 每个 Agent 一个 logo 图标
   - 图标来源：从 `src/lib/agent-adapters.js` 中获取各 agent 的图标/颜色
   - 悬停效果：背景变深
   - 选中状态：白色背景 + 阴影
4. **尺寸**：约 32x32px 图标按钮
5. **间距**：按钮之间有少量间距

#### 交互逻辑

- 点击"全部"按钮：显示所有 Agent 的数据（`agentIds = null`）
- 点击某个 Agent 图标：只显示该 Agent 的数据（`agentIds = [agentId]`）
- 选中状态通过 `useUsageFilters` 中的 `agentIds` 判断
- 切换后触发全局数据刷新

#### 数据来源

- Agent 列表：从 `src/lib/agent-adapters.js` 中获取所有可用 agent
- 选中状态：从 `useUsageFilters` 获取

- 数据随筛选条件变化自动更新

- 小问号图标悬停显示 tooltip 说明

#### 数据来源

- 使用工单1提供的 `useUsageSummary` Hook

  - `cost_usd` → 总成本
  - `cache_hit_rate` → 缓存命中率

### G. 三级筛选级联逻辑

**实现位置**: 在 `useUsageFilters` Hook 中（工单1已定义接口，本工单实现具体级联逻辑）

#### 级联规则

1. **Agent → 来源**：
   - 选择特定 Agent 后，可选来源列表自动过滤为该 Agent 下的 provider
   - 如果之前选中的来源不在新的可选列表中，自动取消选中
   - 如果所有来源都被取消，自动设为"全部来源"

2. **来源 → 模型**：
   - 选择特定来源后，可选模型列表自动过滤为该来源下的模型
   - 如果之前选中的模型不在新的可选列表中，自动取消选中
   - 如果所有模型都被取消，自动设为"全部模型"

3. **反向级联（模型 → 来源 → Agent）**：
   - 选择某个模型时，自动勾选该模型所属的来源
   - 选择某个来源时，自动勾选该来源所属的 Agent
   - 确保筛选状态始终一致，不出现矛盾

4. **数据一致性保证**：
   - 任何筛选变化后，所有下游数据 Hook 自动重新获取数据
   - 使用 React 的依赖数组自动触发

## 注意事项

1. **先看现有代码**：开工前先阅读 `dashboard/src/ui/dashboard/components/` 下现有组件的代码风格
2. **样式规范**：遵循项目现有的 Tailwind CSS 使用方式和颜色变量
3. **组件复用**：尽量复用项目中已有的 UI 组件（按钮、下拉、日历等），不要重复造轮子
4. **工单1依赖**：确保工单1的 API 和 Hooks 已经可用，如未完成先等待或自己 mock 数据
5. **Mock 数据**：如果工单1未完成，可以先用 mock 数据开发 UI，后续再对接真实 API
6. **可访问性**：确保键盘导航、语义化标签、颜色对比度等基本无障碍
7. **性能**：注意下拉列表大数据量时的性能，必要时用虚拟滚动
