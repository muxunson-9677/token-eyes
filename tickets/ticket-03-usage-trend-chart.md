# 工单3：多维度使用趋势图

## 基本信息

- **工单编号**: TICKET-03
- **标题**: 多维度使用趋势图
- **优先级**: 高
- **依赖**: 工单1（后端 API + 数据层）
- **可并行**: 工单2

## 对应需求点

- 需求5.1: 双 Y 轴折线+面积图
- 需求5.2: 5条数据线（输入/输出/缓存创建/缓存命中/成本）
- 需求5.3: 面积渐变填充
- 需求5.4: 丰富 Tooltip
- 需求5.5: 底部图例交互
- 需求7.1: 数据口径一致

## 项目背景

当前 Token Eye 的 Spend 页面只有简单的成本折线图，维度单一。需要参考 CC Switch 的使用趋势图，实现一个多维度、双 Y 轴、带面积填充的丰富趋势图，展示输入、输出、缓存创建、缓存命中、成本等多个维度的变化趋势。

## 技术栈

- React + TypeScript
- 图表库：Recharts（优先，项目可能已有类似依赖；如无则新增）
  - 如果项目已经在用 ECharts 或其他库，优先用现有库
- Tailwind CSS
- 数据：使用工单1提供的 `useUsageTrend` Hook

## 设计参考

视觉风格参考 CC Switch 使用趋势图：
- 双 Y 轴：左 Tokens，右成本
- 5条线：输入（蓝实）、输出（绿实）、缓存创建（橙虚）、缓存命中（紫实）、成本（红虚）
- 面积渐变填充（实线有填充，虚线无或低透明度）
- 丰富的 Tooltip，显示所有维度
- 底部图例，可点击切换显示/隐藏
- 白色卡片背景，圆角

**开工前必读**：先检查项目 `package.json` 和现有图表组件（如 `SpendTrendChart.jsx`、`TrendMonitor.jsx`），确认项目使用的图表库，保持一致。

## 工作内容

### A. 图表组件基础

**组件**: `UsageTrendChart.jsx`
**路径**: `dashboard/src/ui/dashboard/components/UsageTrendChart.jsx`

#### A1. 图表容器

1. **外层卡片**：
   - 白色背景，圆角，内边距
   - 标题栏：
     - 左侧："使用趋势" 标题文字
     - 右侧：当前时间范围标签（如 "30d"），小号灰色文字
   - 标题和图表区域之间有分隔线或间距

2. **图表区域**：
   - 宽度：100% 自适应
   - 高度：约 320px（可根据内容调整）
   - 内边距：左右留出 Y 轴标签空间

#### A2. X 轴（时间轴）

- 位置：底部
- 内容：日期标签
- 格式：
  - 日视图：`MM/DD`（如 `06/14`）
  - 月视图：`MM/DD`
  - 小时视图：`HH:mm`
- 自动疏密：根据数据点数量自动调整显示的标签数量，不重叠
- 样式：灰色文字，小号
- 网格线：无垂直网格线

#### A3. 左 Y 轴（Tokens）

- 位置：左侧
- 内容：Tokens 数量
- 单位自动换算：k（千）/ M（百万）/ B（十亿）
- 刻度：3-5个刻度，自动计算
- 样式：灰色文字，小号
- 网格线：横向虚线网格，浅灰色

#### A4. 右 Y 轴（成本）

- 位置：右侧
- 内容：成本金额（USD）
- 格式：`$0`、`$10`、`$20`...
- 刻度：3-5个刻度，自动计算
- 样式：灰色文字，小号
- 网格线：不额外显示（共用左轴的横向网格线）

---

### B. 5条数据线 + 面积填充

#### B1. 线条规格

| 序号 | 维度 | 颜色 | 线型 | 面积填充 | 对应数据字段 |
|:---:|---|---|---|---|---|
| 1 | 输入 | 蓝色 (#3B82F6 或类似) | 实线 | 有，蓝色渐变 | `input_tokens` |
| 2 | 输出 | 绿色 (#10B981 或类似) | 实线 | 有，绿色渐变 | `output_tokens` |
| 3 | 缓存创建 | 橙色 (#F97316 或类似) | 虚线 | 无（或低透明度填充） | `cache_creation_input_tokens` |
| 4 | 缓存命中 | 紫色 (#8B5CF6 或类似) | 实线 | 有，紫色渐变 | `cached_input_tokens` |
| 5 | 成本 | 红色 (#EF4444 或类似) | 虚线 | 无 | `cost_usd` |

**注意**：具体色值请参考 CC Switch 截图，尽量接近。开工前先看项目现有的颜色变量，保持一致。

#### B2. 面积填充

- 实线类型（输入、输出、缓存命中）：
  - 从线条向下渐变填充到 X 轴
  - 渐变效果：上部颜色较实，下部逐渐透明
  - 透明度：上部约 30%，下部 0%
- 虚线类型（缓存创建、成本）：
  - 无面积填充（或非常低透明度，<10%）

#### B3. 线条样式

- 线宽：约 2px
- 平滑：曲线平滑（bezier 或 monotone）
- 点：默认不显示数据点，hover 时显示
- 层级：缓存命中在最上层，输入、输出在中间，成本在最下层

---

### C. Tooltip

#### C1. 触发方式

- 鼠标悬停在图表上时显示
- 跟随最近的数据点
- 有垂直辅助线（可选）

#### C2. Tooltip 内容

从上到下：
1. **日期标题**：如 `06/14`，加粗
2. **分隔线**
3. **维度列表**：每个维度一行
   - 左侧：彩色圆点 + 维度名称
   - 右侧：数值
   - 数值格式：
     - Tokens 类：带单位（k/M/B）
     - 成本类：带货币符号（$）
   - 颜色：与对应线条颜色一致

示例：
```
06/14
──────────────
● 输入:    1,609,954
● 输出:     152,517
● 缓存创建:       0
● 缓存命中:  17,987,072
● 成本:    $15.093903
```

#### C3. Tooltip 样式

- 白色背景，圆角，阴影
- 内边距：约 12px
- 文字：小号
- 数值右对齐，使用等宽数字字体

---

### D. 底部图例

#### D1. 布局

- 位置：图表下方，水平居中或左对齐
- 排列：水平排列，各项之间有间距
- 背景：透明，与图表在同一卡片内

#### D2. 图例项

每一项包含：
- 彩色圆点（或短线，表示线型）
- 维度名称文字
- 虚线类型用虚线图标区分

#### D3. 交互功能

1. **点击切换显示/隐藏**：
   - 点击图例项，对应曲线和面积显示/隐藏切换
   - 隐藏时：图例文字变灰，透明度降低
   - 显示时：图例文字正常颜色
2. **悬停效果**：
   - 悬停时对应曲线高亮（变粗或其他强调效果）
3. **Y 轴自适应**：
   - 隐藏某些线后，Y 轴范围自动调整以适配剩余数据

---

### E. 数据对接

#### E1. 数据来源

- 使用工单1提供的 `useUsageTrend` Hook
- 或者直接调用 `getSpendTimeseries` API
- 数据格式参考工单1中的 `TrendDataPoint` 接口

#### E2. 数据处理

1. **时间桶适配**：
   - 根据时间范围自动调整时间桶粒度（小时/天/周）
   - 确保 X 轴标签与数据点对应正确

2. **空值处理**：
   - 没有数据的时间点显示为 0 或断开（参考 CC Switch，应该是补0）
   - 全部数据为 0 时显示空状态

3. **数值格式化**：
   - Tokens 单位自动换算（k/M/B）
   - 成本保留适当小数位
   - 大数字用千分位

#### E3. 筛选联动

- 筛选条件变化时自动重新获取数据
- 切换时间范围时 X 轴格式自动调整
- loading 状态显示骨架屏或加载动画

---

### F. 响应式与性能

#### F1. 响应式

- 宽度：100% 自适应父容器
- 高度：固定高度或最小高度
- 小屏幕下：
  - X 轴标签减少
  - 图例可能换行
  - Tooltip 位置自动调整

#### F2. 性能优化

1. **大数据量处理**：
   - 数据点 > 1000 个时自动采样降频
   - 确保 60fps 流畅渲染

2. **重绘优化**：
   - 避免不必要的重绘
   - 使用 memo 优化组件

#### F3. 边界情况

1. **空数据**：
   - 显示友好的空状态提示（如 "暂无数据"）
   - 图表区域显示占位图形或文字

2. **单条数据**：
   - 正常显示点和 tooltip

3. **加载中**：
   - 显示骨架屏或 loading 动画

4. **错误状态**：
   - 显示错误提示和重试按钮

## 注意事项

1. **先检查现有图表库**：不要新增项目没有的图表库，优先用已有库。开工前先 `grep recharts` 或 `grep echarts` 确认。
2. **参考现有组件**：先读 `SpendTrendChart.jsx` 和 `TrendMonitor.jsx`，保持代码风格一致。
3. **数据口径一致**：确保图表汇总数据与统计面板一致，有问题先排查数据层。
4. **工单1依赖**：如果工单1未完成，先用 mock 数据开发 UI，后续再对接真实 API。
5. **性能优先**：趋势图是性能敏感区域，注意大数据量下的渲染性能。
6. **颜色一致性**：使用项目已有的颜色变量，不要硬编码颜色值。
7. **无障碍**：确保图表有适当的 aria 标签和文字说明。
