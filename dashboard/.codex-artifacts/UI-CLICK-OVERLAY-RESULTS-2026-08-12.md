# 小组件点击回弹与 Agent 覆盖浮层验收结果

## 修复结果

- 小组件页使用页面级事件委托，所有可用的 `button`、`select` 和 `role="button"` 控件在快速点击后都会完整播放 300ms 动画。
- 动画阶段为：原位 → `translateY(2px) scale(0.94)` → `translateY(-1px) scale(1.015)` → 原位。
- Agent 明细放入相对定位的卡片舞台，明细本身使用绝对定位、独立滚动、实体背景和高层级阴影。
- 明细展开不再参与父级高度计算，直接覆盖下方卡片。
