你好 Claude，我需要开发（或基于现有项目二开）一个 **AI Token 用量统一监控面板**，请帮我评估并给出实现方案。

### 一、项目核心目标
我不想用任何模型切换功能，**只要一个纯粹的跨平台 Token 用量监控仪表盘**，用来统一查看所有 AI 编程助手在不同环境下的 Token 消耗。

### 二、需要监控的具体对象（Agent 与模型）
我的工具链涉及以下 Agent，它们接入了多个平台的模型（DeepSeek、豆包、GLM、Xiaomi、Qwen 等）：

1. **Hermes** (当前在 CC Switch 上没有使用统计)
2. **Codex**
3. **Claude Code**
4. **OpenClaw** (当前在 CC Switch 上没有使用统计)

### 三、必须实现的功能细节
1. **统一汇总**：将所有 Agent、所有模型的 Token 输出汇总在一个界面。
2. **清晰分类**：
   - 区分来自哪个渠道（Agent 名称）和具体的哪个模型。
   - 区分计费方式：**API Key（按量付费）** 和 **Token Plan（订阅套餐包）**。
3. **套餐专属标记**：对于 Token Plan，必须醒目显示该套餐的 **套餐内容**、**订阅时间** 和 **剩余时间/余量、5小时额度/周额度**。
4. **实时/准实时监测**：能动态刷新用量。
5. **预留扩展接口**：后续新增 OpenClaw 或其他插件时，能通过标准化接口（如 RESTful API 或读取本地文件）轻松接入。
6.**精准检测token**：token消耗检测准确到具体字符（可参考github项目或skills的的精准捕捉）还有token缓存命中率。
7.**花销统计**：用户可自定义输入什么时间区间在哪个平台充值消费了多少，apikey的花销实时计费增加，并有一个可视化展示综合所有支出（当天/周/月/综合累计），不同平台有不同的计费折线，鼠标放置上可显示费用（参考cc switch使用统计可视化折线图）。

### 四、运行环境（极其重要）
- **我的电脑是 Windows 系统，但 Agent 同时运行在 Win 环境和 WSL 环境**。
- 监控面板必须能同时检测并展示 **宿主机 (Windows)** 和 **WSL (Linux)** 两个环境下的所有 Token 数据，在统一的界面展示，不能分开看。

### 五、开发基准与约束条件
1. **参考对象**：我觉得 **CC Switch (`farion1231/cc-switch`)** 跨 Win/WSL 检测很好。可以只参考它的“用量统计”和“跨环境检测”核心能力。以Token tracker为基线，移植cc switch的WSL路径桥接思路
2. **新增适配**：需要为 **Hermes** 和 **OpenClaw** 编写新的数据采集适配器（因为 CC Switch 原生不支持统计它们）。
3. **我的代码能力**：**我完全不会写代码**，整个开发过程我将全程依靠 **Codex** 作为总把控任务拆解掌握进度派发工单， **Claude Code**  作为工单执行者AI 编程助手来完成。
