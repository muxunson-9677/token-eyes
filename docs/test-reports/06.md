## 实现验证

### 类型定义 ✅
- `CostLedgerQuery` - 查询参数接口
- `CostLedgerByAgent` - 按代理类型统计
- `CostLedgerSummary` - 花销汇总响应
- `SpendOverviewBarDatum` - 柱状图数据点
- `SpendOverviewViewModel` - 组件视图模型

### API 层 ✅
- `usageApi.getCostLedgerSummary(params?)` - 调用 `get_cost_ledger_summary` Tauri 命令

### Query 层 ✅
- `usageKeys.costLedger()` - query key 定义
- `useCostLedgerSummary(params?, options?)` - React Query hook

### 组件 ✅
- Loading 状态: 显示加载动画
- Error 状态: 显示错误提示 "加载失败"
- Success 状态:
  - 显示 "本周期花销" 金额 (来自 `totalCostUsd`)
  - 显示 "累计花销" 金额 (来自 `cumulativeTotalCostUsd`)
  - 渲染两根柱子的柱状图 (period 蓝色, cumulative 绿色)

### 数据口径验证 ✅
- `monthlyUsd` 使用 `CostLedgerSummary.totalCostUsd` = `17.34` → 显示 `$17.3400`
- `cumulativeUsd` 使用 `CostLedgerSummary.cumulativeTotalCostUsd` = `175.50` → 显示 `$175.5000`
