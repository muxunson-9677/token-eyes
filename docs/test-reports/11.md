# Step 11 Test Report: backend MVP chain

Date: 2026-06-17
Branch: `feature/11-backend-chain-smoke`

## Scope

This step verifies the backend chain only. It does not depend on frontend UI.

Covered chain:

- Hermes local `state.db` session import.
- Standard usage storage in `proxy_request_logs`.
- Manual subscription fee storage in `subscription_fees`.
- Monthly and cumulative spend aggregation through `get_cost_ledger_summary`.

Note: the project baseline stores standard usage rows in `proxy_request_logs`; this is the implementation equivalent of the original plan's `usage_records`.
