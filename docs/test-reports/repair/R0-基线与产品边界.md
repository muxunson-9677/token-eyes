- 输出中有 99 行包含真实用户主目录路径（报告中统一脱敏为 `<USER_HOME>`）；

- 首轮执行还出现实际 Provider quota 分支。

报告只记录计数和脱敏路径，未复制账号、Cookie、Token 或 queue 内容。R1 完成前不再把全套 Node 结果作为可信业务结论，也不运行会回退到真实 HOME 的 Token 审计。
