## 已落实的固定契约

1. `visibleProviderIds === undefined` 不增加 Provider 可见性过滤，保留调用方已有 `sources`。
2. `visibleProviderIds === []` 表示用户明确隐藏全部，Hook 直接返回空且不发起用量请求。
3. `visibleProviderIds` 为非空数组时，与调用方已有来源筛选求交集。
4. Spend 页面测试统一补齐 Router、Theme、Locale；页面自身继续提供 UsageFilters Context，避免重复 Provider。
5. Native Bridge 使用精确 `.d.ts` 声明覆盖公开接口，没有使用宽泛 `any`。
6. `kimi_api_budget` 只保存 `api_key_ref`，并主动清除陈旧 `account_binding_id`。
7. Kimi Code 官方套餐保存 `account_binding_id`，并主动清除陈旧 `api_key_ref`。
8. 两种 Kimi 套餐均保存对应 Provider 官方首页，保存后重新挂载和刷新不串字段。
9. 删除重复、不可达的 Kimi 条件分支和多余布尔转换。

## TDD 与缺陷闭环

先以失败测试复现，再实现并转绿：

- 未传 `visibleProviderIds` 时错误地向请求传入 `sources: []`。
- Spend 页面 9 项测试因缺少 Router 出现 `useNavigate()` 未处理异常。
- TypeScript 缺少 `visibleProviderIds`、Native Bridge 声明及 `.ts` 动态导入配置。
- ESLint 报告多余布尔转换和重复 Kimi 条件。
- Kimi API Budget 会残留 console session binding。
- Kimi Code 官方套餐在无旧 binding 时不会写入新连接 session，且可能残留 API key。

所有 R3 新增和既有回归测试均已转绿。

- 浏览器 `pageerror` 为 0，未处理 React/`useNavigate` 控制台错误为 0。
- 隔离未登录、禁外网环境仍会产生预期的资源 401 和 `ERR_NETWORK_ACCESS_DENIED`；不属于 React 未处理异常，也不作为 R3 产品回归。
