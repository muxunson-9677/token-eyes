| `cost_multiplier` | `"1.0"` |
| `created_at` | `sessions.started_at`（毫秒自动转秒） |

### 成本规则

1. `actual_cost_usd > 0` → 直接使用，分项写 `"0"`
2. `estimated_cost_usd > 0` → 直接使用，分项写 `"0"`
3. 均为 0 → `CostCalculator.calculate_for_app("hermes", ...)` + `find_model_pricing`
   - 先尝试 `{normalized_provider}/{model}`，再尝试 `{model}`

### Provider 归一化

- `anthropic/*` → `anthropic`
- `openai/*` → `openai`
- `google/*` / `gemini/*` / `vertex/*` → `google`
- 其它 → 转小写，`-` 替换为 `_`

### 过滤规则

- `model IS NULL OR TRIM(model) = ''` → SQL 层跳过
- `id` 为空 → 代码层跳过
- 所有 token 为 0 且成本 ≤ 0 → 跳过
- `should_skip_session_insert` 去重
