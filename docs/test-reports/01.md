| `created_at` | `sessions.started_at`（毫秒自动转秒） |

### 成本规则

1. `actual_cost_usd > 0` → 直接使用，分项写 `"0"`
2. `estimated_cost_usd > 0` → 直接使用，分项写 `"0"`
3. 均为 0 → `CostCalculator.calculate_for_app("hermes", ...)` + `find_model_pricing`
   - 先尝试 `{normalized_provider}/{model}`，再尝试 `{model}`

### Provider 归一化

- `anthropic/*` → `anthropic`
- `openai/*` → `openai`
- `google/*` / `gemini/*` / `vertex/*` → `google`
- 其它 → 转小写，`-` 替换为 `_`

### 过滤规则

- `model IS NULL OR TRIM(model) = ''` → SQL 层跳过
- `id` 为空 → 代码层跳过
- 所有 token 为 0 且成本 ≤ 0 → 跳过
- `should_skip_session_insert` 去重

## 编译与测试状态

### 本地编译

**未通过** — 当前 WSL 环境缺少 Tauri 构建所需的系统依赖（`pkg-config`, `libgtk-3-dev`, `libssl-dev`, `libsoup-3.0-dev`, `libwebkit2gtk-4.1-dev`），且无 `sudo` 权限安装。

需要在有完整 Tauri 开发环境的机器上运行：

```bash
# 安装依赖（Ubuntu/Debian）
sudo apt install -y pkg-config libssl-dev libgtk-3-dev libsoup-3.0-dev \
    libjavascriptcoregtk-4.1-dev libwebkit2gtk-4.1-dev

# 编译检查
cargo check --manifest-path src-tauri/Cargo.toml

# 运行测试
cargo test --manifest-path src-tauri/Cargo.toml usage_source_hermes
cargo test --manifest-path src-tauri/Cargo.toml session_usage
```
