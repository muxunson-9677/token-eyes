## 公式验证

- `period_total_usd = token_cost_usd + subscription_cost_usd` — 用例 3 验证: 3 + 10 = 13 ✅
- `cumulative_total_usd = cumulative_token_cost_usd + cumulative_subscription_cost_usd` — 用例 3 验证: 3 + 60 = 63 ✅
- 订阅费按自然月计次（不按天拆分）— 用例 4 验证: 2 个月 × 25 = 50 ✅
- 只纳入 `currency = 'USD'` 的订阅 — 实现中硬编码 `WHERE currency = 'USD'` ✅
- 金额字段均以 6 位小数字符串返回 — 所有用例验证 ✅
