## 数据目录覆盖

V2.1 需要 Windows 端 Token Eyes 同时读取 Windows Codex、WSL Claude Code、WSL Hermes Agent 的日志。

最小配置结构:

```json
{
  "dataDirectories": {
    "claude": "\\\\wsl.localhost\\Ubuntu\\home\\hermes\\.claude",
    "codex": "C:\\Users\\<user>\\.codex",
    "hermes": "\\\\wsl.localhost\\Ubuntu\\home\\hermes\\.hermes"
  }
}
```

迁移到 TokenTracker 后的默认路径:

- Claude Code: `${HOME}/.claude/projects`
- Codex: `${CODEX_HOME || HOME/.codex}/sessions` 和 `${CODEX_HOME || HOME/.codex}/archived_sessions`
- Hermes Agent: `${TOKENTRACKER_HERMES_HOME || HOME/.hermes}/state.db`,并包含 `profiles/*/state.db`

UNC 路径规则:

- 接受 `\\wsl.localhost\<distro>\home\<user>\...`。
- 接受 `\\wsl$\<distro>\home\<user>\...`。
- Hermes 的 UNC SQLite DB 读取必须保留 TokenTracker 现有的本地快照机制。
- 路径覆盖是本地设置,不得上传到云同步。

## V2.1 计价规则

V2.1 使用“每个 Agent 一个默认单价”的简化方案,不是最终版的“每个 Agent + model 一个单价”。

```json
{
  "agentDefaultPricing": {
    "claude": { "inputUsdPer1M": 0, "outputUsdPer1M": 0 },
    "codex": { "inputUsdPer1M": 0, "outputUsdPer1M": 0 },
    "hermes": { "inputUsdPer1M": 0, "outputUsdPer1M": 0 }
  }
}
```

公式:

```text
cost_usd =
  input_tokens / 1_000_000 * inputUsdPer1M
  + output_tokens / 1_000_000 * outputUsdPer1M
  + cached_input_tokens / 1_000_000 * inputUsdPer1M
  + cache_creation_input_tokens / 1_000_000 * inputUsdPer1M
  + reasoning_output_tokens / 1_000_000 * outputUsdPer1M
```

如果某个数据源没有用户自定义价格,V2.1 显示 `0` 成本,不要回退到 Anthropic/OpenAI 的内置定价,避免误导。

## V2.1 USD/CNY

使用一个 MVP 固定常量:

```js
const MVP_USD_TO_CNY = 7.2;
```

凡是 MVP 成本展示处,同时显示 USD 和 CNY。V2.1 不做可配置汇率设置。

## 缓存命中率

Dashboard 卡片字段:

- `cachedTokens = totals.cached_input_tokens`
- `inputLikeTokens = totals.input_tokens + totals.cached_input_tokens + totals.cache_creation_input_tokens`
- `cacheHitRate = inputLikeTokens > 0 ? cachedTokens / inputLikeTokens : 0`

同时展示缓存命中 token 数和百分比。

## 订阅/花销记录 MVP

V2.1 只做手动新增、列表展示、简单求和。

字段:

- `id`
- `source`: `claude` / `codex` / `hermes` / 非空自定义字符串
- `plan_label`
- `amount`
- `currency`: `USD` 或 `CNY`
- `note`
- `created_at`

简单汇总:

- `total_usd = sum(USD amounts) + sum(CNY amounts / MVP_USD_TO_CNY)`
- `total_cny = total_usd * MVP_USD_TO_CNY`

V2.1 不做月付/年付/一次性周期换算。

## Token Plan 占位表单

只实现手动静态录入:

- `source`
- `plan_label`
- `total_quota`
- `used_quota`
- `remaining_quota`
- `expires_at`

V2.1 不实现刷新间隔、官方 API 轮询、Cookie 抓取、凭证存储或后台任务。
