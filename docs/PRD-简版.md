# Token Eyes 产品需求文档（简版）

> 写给不懂技术的朋友：说明这个产品是什么、解决什么问题、和别人有什么不一样。

---

## 一、一句话介绍

**Token Eyes 是一款「AI 用量与成本记账本」**——自动统计你在各种 AI 编程工具上用了多少、花了多少钱，全部在你自己电脑上完成，**无需登录、无需注册、无需 API Key**。

类比：像手机上的「流量统计」或「记账 App」，只不过记的是 **AI 使用量与订阅支出**，不是话费或外卖。

---

## 二、为什么要做这个产品？

市面上常见方案各有短板：

| 常见方案 | 局限 |
|----------|------|
| **CC Switch 等热门工具** | 只能显示少数几个 Agent 的使用统计，覆盖面窄 |
| **各类 Token 检测站** | 往往只支持单一系统（比如只能 Mac，或只能 Windows），或者**多账号显示不全** |
| **各 AI 工具自带统计** | 各看各的，没法汇总；订阅费和按量费用也散在不同地方 |

**Token Eyes 的定位：把这些优势综合成一体。**

不管你是 Windows 还是 WSL 环境，只要是可选的 Agent，都能显示使用统计；多个账号可以汇总成统一消耗视图；还能登记过往的 AI 类订阅支出，我们会帮你累积成本，清晰可查——**完全本地、完全服务于你个体，不需要登录任何云端账号。**

---

## 三、目标用户

| 用户类型 | 典型场景 |
|----------|----------|
| 程序员 / AI 重度用户 | 同时用多款 AI 写代码，想控制总成本 |
| 多账号用户 | 有多个 Claude / Codex / Cursor 等账号，想一眼看清合计花了多少 |
| 注重隐私的用户 | 不想把聊天内容上传到第三方，只要本地记账 |
| Windows + WSL 用户 | 两边都在用 AI，希望**同一套工具、同一套统计** |

---

## 四、核心价值（和别人比，强在哪）

1. **覆盖面广** — 可选 Agent 都能显示使用统计，不挑平台、不挑少数几个热门工具  
2. **跨环境统一** — **Windows 和 WSL** 都能检测，不用为了看用量换系统或换工具  
3. **多账号汇总** — 多个账号的消耗合并成一张总账，不再「每个账号各看各的、加不起来」  
4. **成本可累积** — 可登记过往 AI 订阅支出（月费、年费等），与实时 token 消耗一起累积，长期花费一目了然  
5. **完全本地** — 无需登录，数据留在本机，不上传聊天内容，只服务于你个人  
6. **开箱即用** — 安装后自动识别已有 AI 工具，尽量零配置

## 五、主要功能

### 5.1 核心功能

| 功能 | 大白话说明 |
|------|------------|
| **自动采集用量** | 你用 AI 写代码时，后台自动记 token 数量 |
| **Agent 可选、统计齐全** | 支持的 Agent 都能在面板里看到用量，不遗漏 |
| **用量仪表盘** | 图表展示今天 / 本周 / 本月用了多少、趋势如何 |
| **按模型 / 工具拆分** | 例如 Claude、GPT、Cursor 各用了多少 |
| **多账号统一消耗** | 多个账号合并汇总，看「总共花了多少」 |
| **成本估算与累积** | 按公开定价估算 token 费用；登记历史订阅后，**累积总成本**清晰可查 |
| **活跃度热力图** | 类似 GitHub 绿格子，一眼看出哪天用得猛 |
| **限额提醒** | 部分平台可显示配额还剩多少、何时重置 |

### 5.2 使用形态

| 形态 | 说明 |
|------|------|
| **本地网页仪表盘** | 浏览器打开本机地址即可查看（仅本机可访问） |
| **Windows 桌面应用** | 系统托盘常驻，点开即看 |
| **WSL 环境** | 与 Windows 侧一致，可在 Linux 子系统内完成检测与统计 |

### 5.3 明确不做的事

- 不是 AI 聊天客户端（不能代替 Claude、Cursor 去对话）  
- 不收集、不分析你的 prompt 和 AI 回复内容  
- 不强制登录云端；排行榜、云同步等如有，均为可选，默认纯本地  
- 不替代各平台官方发票，而是帮你**实时汇总 + 长期记账**

## 六、工作原理（概念图）

```
┌─────────────────────────────────────────────────┐
│  你用的 AI 工具（多种 Agent，可多账号）            │
│  Windows 本机  /  WSL 环境                       │
└────────────────────┬────────────────────────────┘
                     │ 自动记录 token + 可登记订阅支出
                     ▼
┌─────────────────────────────────────────────────┐
│  Token Eyes（跑在你电脑上）                      │
│  · 多 Agent、多账号汇总                          │
│  · 实时用量 + 历史订阅 → 累积成本                │
│  · 本地网页 / 桌面 App 展示                      │
└────────────────────┬────────────────────────────┘
                     │
                     ▼
              仪表盘：清晰可查，无需登录
```

**日常流程：**

1. 安装一次  
2. 像以前一样用 AI（Win 或 WSL）  
3. 需要查账时打开 Token Eyes，看统一汇总与累积成本

## 七、隐私原则

| 会记录 | 不会记录 |
|--------|----------|
| Token 数量、使用时间 | 你问了 AI 什么问题 |
| 用的哪个模型 / Agent / 账号标识 | AI 回答了什么 |
| 你主动登记的订阅金额与时间 | 代码、文件、聊天正文 |

**默认完全本地运行，不登录也能用满核心功能。**

## 八、成功标准（产品好不好，看这些）

| 指标 | 期望 |
|------|------|
| 环境覆盖 | Windows 与 WSL 均可稳定检测 |
| Agent 覆盖 | 可选 Agent 均有使用统计，无明显「只显示一两个」的缺口 |
| 账号汇总 | 多账号消耗可合并，数字可对得上 |
| 成本清晰 | 实时 token 费用 + 登记订阅 → 累积成本可查 |
| 隐私与门槛 | 无需登录；用户能理解「只记数字与金额、不记聊天」 |
| 上手成本 | 安装后短时间内能看到第一份数据 |

## 九、产品口号

> **多 Agent、多账号、多环境——你的 AI 花费，一本账看清。**

更白话版：

> **不管 Win 还是 WSL，用了多少、订了多少、一共花了多少，本地记账，不用登录。**

## 十、给朋友的 TL;DR（三句话）

1. **它是什么**：把 CC Switch、各类 Token 站的短板补全后的 **AI 用量 + 订阅成本记账本**。  
2. **强在哪**：Win / WSL 都能用；可选 Agent 都能统计；多账号汇总；过往订阅可登记、成本可累积。  
3. **安不安全**：全本地、不登录，只记用量和金额，不记聊天内容。
