## 比较范围

- 仅复刻图片中左侧导航分隔线右侧的内容页；应用既有标题栏和既有侧边栏继续使用，不纳入像素比较范围。
- 首轮视觉验收以右侧内容根节点的实际 DOM 边界裁切运行截图，再与参考图中相同内容区域比较。图片中可见的侧边栏分隔线大约位于 x=263（价值对比）和 x=260（实时会话）；这只是首次裁切的起点，必须由首次运行截图的 DOM 边界复核后记录最终值。
- 设计稿中出现的金额、Token、Agent 名称、日期、趋势线和百分比均是视觉层级、布局和状态表达示例，不得当作生产数据或伪造为真实数据。

## 价值对比视觉清单

1. 顶部标题、说明、时间范围分段控件、数据真实性提示。
2. 三段式主指标：实际支出、使用价值、价值倍数；未知或估算数据需要清楚标识，不能显示为精确值。
3. 数据口径/覆盖度摘要带。
4. 月度构成、套餐价值对比表、近六个月趋势图。
5. 详情折叠区、空态、部分数据态、授权缺失态和无匹配套餐态。

## 实时会话视觉清单

1. 标题、隐私说明、日期范围、更新时间和手动刷新。
2. 活跃 Agent、实时 Token/Credits、API 等价值三项摘要。
3. 当前焦点会话卡片及其他会话卡片。
4. 会话构成、趋势、子 Agent、请求明细和右侧数据状态/价格覆盖率/图例面板。
5. 单位分离、刷新、状态切换、空态、仅配额态、部分数据态和隐私保护提示。
