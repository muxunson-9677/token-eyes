# 工单 07: SubscriptionFeeForm 订阅费表单

## 任务编号与分支名

- 编号: `07`
- 分支: `feature/07-subscription-fee-form`

## 背景说明

Day1 已完成 `subscription_fees` 表和 `subscription_fee_commands` 后端 CRUD。Token Eyes MVP 需要一个手动订阅费表单，让用户录入、编辑、删除订阅费，用于后续 `cost_ledger` 聚合。

## 允许改动的目标文件清单

- `src/types/subscriptionFees.ts`
- `src/lib/api/subscriptionFees.ts`
- `src/lib/query/subscriptionFees.ts`
- `src/lib/query/index.ts`
- `src/components/usage/SubscriptionFeeForm.tsx`
- `tests/components/SubscriptionFeeForm.test.tsx`
- `docs/test-reports/07.md`

## 已确定的输入规范

接口定义以 `docs/dev-notes/interfaces.md` 的 `Day 2 前端组件数据接口` / `订阅费表单数据接口` 为准。

前端 API:

```ts
subscriptionFeeApi.list(params?: SubscriptionFeeListQuery): Promise<SubscriptionFee[]>
subscriptionFeeApi.create(input: SubscriptionFeeInput): Promise<SubscriptionFee>
subscriptionFeeApi.update(id: number, input: SubscriptionFeeInput): Promise<SubscriptionFee>
subscriptionFeeApi.remove(id: number): Promise<void>
```

Tauri 命令:

```ts
invoke<SubscriptionFee[]>("list_subscription_fees", { agentType, includeInactive })
invoke<SubscriptionFee>("create_subscription_fee", { input })
invoke<SubscriptionFee>("update_subscription_fee", { id, input })
invoke<void>("delete_subscription_fee", { id })
```

表单字段:

- `agentType`
- `planLabel`
- `monthlyFee`
- `currency`
- `billingDay`
- `effectiveFromDate`
- `effectiveToDate`
- `note`

## 具体步骤

1. 新增 `src/types/subscriptionFees.ts`，定义 `SubscriptionFee`、`SubscriptionFeeInput`、`SubscriptionFeeFormValues`、`SubscriptionFeeListQuery`。
2. 新增 `src/lib/api/subscriptionFees.ts`，封装四个 Tauri 命令。
3. 新增 `src/lib/query/subscriptionFees.ts`，提供 list query 和 create/update/delete mutation，并在成功后失效订阅费 query。
4. 在 `src/lib/query/index.ts` 导出 subscription fee query 模块。
5. 新增 `src/components/usage/SubscriptionFeeForm.tsx`，使用现有 `react-hook-form`、`zod` 和 `src/components/ui/*` 表单组件。
6. 表单校验规则:
   - `agentType` 必填。
   - `planLabel` 必填。
   - `monthlyFee` 为非负十进制字符串。
   - `currency` 固定默认 `USD`。
   - `billingDay` 为 1-31。
   - `effectiveFromDate` 必填。
   - `effectiveToDate` 为空或不早于 `effectiveFromDate`。
7. 组件提供列表展示、创建、编辑、删除的最小交互；删除前使用现有确认模式或轻量确认文案。
8. 增加 `tests/components/SubscriptionFeeForm.test.tsx`，mock API/query，验证创建表单校验和提交 payload。
9. 自测并把结果写入 `docs/test-reports/07.md`。
