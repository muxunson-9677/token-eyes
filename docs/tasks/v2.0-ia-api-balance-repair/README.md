## 修复后产品边界

- 供应商 API 只查询账户余额、月花销、累计花销、币种与同步状态。
- 不允许模型调用、提示词、请求正文配置、聊天代理或通用 API 调试。
- API Key 不能进入命令行参数、环境变量、普通文件、前端存储、日志、错误、截图或跨域重定向。
- 设置 > 成本设置必须实时展示账户财务数据，不只显示“已配置”。
- 支出 > 成本累积继续展示财务结果和订阅记录。
- 订阅记录只支持后端真实支持的 USD/CNY；一次性周期统一使用 API 值 `one_time`。
