## 中文简述

本目录用于修复当前版本中“界面能打开，但真实数据、交互和发布证据不足”的问题。为控制 Token 成本，只拆成 3 个工单：`01` 和 `02` 由同一个主线 subagent 串行执行，`03` 必须由全新、独立的审查 subagent 执行。

## 贝叶斯验收基线

假设：`H = 当前产品已经可以作为真实数据体验版上线并通过最终验收`。

以下数值是工程验收估计，不是统计实验；相互关联的证据按证据组折扣，不重复放大。

| 证据组 | 本轮实测证据 | 方向 | 似然比估计 |
|---|---|---:|---:|
| 先验 | 上一轮修复审查声称 01/02/03 已通过 | 正向 | `P(H)=35%` |
| 专项验证 | 后端专项 106/106、前端专项 67/67、构建、类型检查、目标 ESLint、`cargo check` 通过 | 正向 | `3.0` |
| 真实分页 | 后端有 5000 条 Codex 请求，UI 只显示“10 / 10”，无第 2 页 | 强负向 | `0.10` |
