# 工单 06: SpendOverviewChart 花销图表

## 任务编号与分支名

- 编号: `06`
- 分支: `feature/06-spend-overview-chart`

## 背景说明

Day1 已完成 `cost_ledger` 后端聚合查询。Token Eyes MVP 的前端需要一个简化花销图表，只展示本统计周期花销、历史累计花销两个数字，并用两根柱子做基础对比。

## 允许改动的目标文件清单

- `src/types/usage.ts`
- `src/lib/api/usage.ts`
- `src/lib/query/usage.ts`
- `src/components/usage/SpendOverviewChart.tsx`
- `tests/components/SpendOverviewChart.test.tsx`
- `docs/test-reports/06.md`

## 已确定的输入规范

接口定义以 `docs/dev-notes/interfaces.md` 的 `Day 2 前端组件数据接口` / `花销图表数据接口` 为准。

前端 API:

```ts
usageApi.getCostLedgerSummary(params?: CostLedgerQuery): Promise<CostLedgerSummary>
```

Tauri 命令:

```ts
invoke<CostLedgerSummary>("get_cost_ledger_summary", {
  startDate,
  endDate,
  agentType,
})
```

组件数据口径:

- `monthlyUsd` 使用 `CostLedgerSummary.totalCostUsd`。
- `cumulativeUsd` 使用 `CostLedgerSummary.cumulativeTotalCostUsd`。
- 柱状图只展示 `period` 和 `cumulative` 两根柱。

## 具体步骤

1. 在 `src/types/usage.ts` 增加 `CostLedgerQuery`、`CostLedgerByAgent`、`CostLedgerSummary`、`SpendOverviewBarDatum`、`SpendOverviewViewModel` 类型。
2. 在 `src/lib/api/usage.ts` 增加 `getCostLedgerSummary(params?: CostLedgerQuery)`，只调用 Day1 已注册的 `get_cost_ledger_summary`。
3. 在 `src/lib/query/usage.ts` 增加 cost ledger query key 和 `useCostLedgerSummary` hook，复用现有 range 解析逻辑。
4. 新增 `src/components/usage/SpendOverviewChart.tsx`。
5. 组件内部使用 `useCostLedgerSummary` 拉取数据，展示本周期花销、累计花销两个数字。
6. 使用项目已有 `recharts` 实现两根柱子的简易柱状图，样式贴近现有 `UsageTrendChart`，不要做额外视觉打磨。
7. 增加 `tests/components/SpendOverviewChart.test.tsx`，mock hook 或 API，验证两个金额数字和两根柱数据标签能渲染。
8. 自测并把结果写入 `docs/test-reports/06.md`。
