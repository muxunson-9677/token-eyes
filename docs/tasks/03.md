# 工单 03: 前端新增 Hermes 筛选 Tab

## 任务编号与分支名

- 编号: `03`
- 分支: `feature/03-hermes-usage-tab`

## 背景说明

用量 Dashboard 顶部已有按应用筛选按钮。本任务按现有 OpenCode 的实现模式加入 Hermes，使第 01 工单导入的数据可以通过 `app_type = "hermes"` 筛选展示。

## 允许改动的目标文件清单

- `src/types/usage.ts`
- `src/components/usage/UsageDashboard.tsx`
- `src/components/usage/UsageHero.tsx`
- `src/components/usage/DataSourceBar.tsx`
- `src/i18n/locales/en.json`
- `src/i18n/locales/zh.json`
- `src/i18n/locales/zh-TW.json`
- `src/i18n/locales/ja.json`
- `docs/test-reports/03.md`

## 已确定的输入规范

- 新增筛选值: `hermes`。
- 前端 `AppType` 增加 `"hermes"`。
- `KNOWN_APP_TYPES` 顺序: `claude`, `codex`, `gemini`, `opencode`, `hermes`。
- 图标名使用现有 `ProviderIcon` 的 `"hermes"`。
- 数据来源 label key: `usage.dataSource.hermes_session`。

## 具体步骤

1. 在 `src/types/usage.ts` 中把 `hermes` 加入 `AppType` 和 `KNOWN_APP_TYPES`。
2. 在 `UsageDashboard.tsx` 中给 `APP_FILTER_ICON` 增加 `hermes: "hermes"`。
3. 在 `UsageHero.tsx` 中给 `TITLE_THEMES` 增加 Hermes 主题，保持现有风格结构即可。
4. 在 `DataSourceBar.tsx` 中给 `hermes_session` 增加文件类图标。
5. 在四份 locale 中增加:
   - `usage.appFilter.hermes`
   - `usage.dataSource.hermes_session`
6. 不改 Dashboard 布局，不改查询参数结构。
7. 自测并把结果写入 `docs/test-reports/03.md`。

- `pnpm typecheck` 通过。

- 当后端返回 `app_type = "hermes"` 数据时，Hero、趋势图、列表、来源统计、模型统计均受筛选影响。
- PR 改动只涉及允许文件。
