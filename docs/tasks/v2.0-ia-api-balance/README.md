# Token Eyes 信息架构与供应商余额改造总调度

## 中文简述

本目录把已确认的修改意见拆成 4 个最小长工单。目标是把支出和设置改成左侧二级导航，并新增只用于查询供应商账户花销与余额的 API 配置能力。API 配置不得用于模型调用，不得发送提示词，不得成为通用代理。

## 最终信息架构

```text
概览

支出
- 使用统计
- 成本累积

设置
- 基础设置
- 成本设置
```

固定路由：

```text

```

兼容入口：

- `/spend` 重定向到 `/spend/usage`。
- `/settings` 重定向到 `/settings/basic`。
- Tauri 默认入口重定向到 `/settings/basic`。

## 功能归属

| 页面 | 必须包含 | 明确不包含 |
|---|---|---|
| 支出 > 使用统计 | 真实 Token、成本卡片、趋势、Provider 统计、模型统计、请求日志 | 独立“按来源拆分”表、Token 套餐配置、API Key |
| 支出 > 成本累积 | Token 套餐状态、供应商账户花销与余额、订阅记录及成本汇总 | API Key 明文、模型调用配置 |
| 设置 > 基础设置 | 外观、菜单栏、账户、数据目录、环境检测、Agent 计费规则、限制显示及其他非成本配置 | Token 套餐、供应商 API 配置 |
| 设置 > 成本设置 | Token 套餐管理、供应商 API 配置 | 外观、数据目录、限制显示、模型调用入口 |

## 供应商 API 的硬边界

- 只允许查询账户余额、累计花销、本月花销、币种、同步状态和更新时间。
- 不允许调用 chat、completions、responses、messages、embeddings、images 等模型推理接口。
- 不发送提示词、对话、项目数据、Token 日志或用户文件。
- API Key 只能进入本机安全凭据存储；配置、日志、响应、截图、测试快照和 Git 文件不得出现明文。
- 页面只能拿到脱敏元数据和财务结果，不能读取 API Key。
- 供应商没有官方财务接口时显示“不支持自动查询”，不得用 Token 估算值冒充真实账户余额。
- “实时”定义为：进入页面立即刷新、支持手动刷新、支持不短于 60 秒的定时刷新；不要求 WebSocket。

## 统一数据契约

后端和前端必须先锁定以下语义，字段可按项目风格使用 snake_case 或 camelCase，但接口两端必须一致并有契约测试。

```ts
type ProviderApiConfig = {
  id: string;
  providerId: string;
  label: string;
  requestUrl: string;
  requestMethod: "GET" | "POST";
  authType: "bearer" | "header";
  authHeaderName?: string;
  apiKeyRef: string;
  nonSecretHeaders?: Record<string, string>;
  balancePath: string;
  monthSpendPath?: string;
  lifetimeSpendPath?: string;
  currencyPath?: string;
  refreshIntervalSeconds: number;
  enabled: boolean;
};

type ProviderAccountBalance = {
  configId: string;
  providerId: string;
  accountLabel: string;
  balance: number | null;
  monthSpend: number | null;
  lifetimeSpend: number | null;
  currency: string | null;
  status: "synced" | "not-connected" | "unsupported" | "error";
  lastSyncedAt: string | null;
  errorCode?: string;
  errorMessage?: string;
};
```

禁止把任意可执行脚本、JavaScript 表达式、模板代码或用户函数保存为响应解析规则。响应字段映射只能使用受限的点路径，例如 `data.balance`。

## 贝叶斯验收表

### 计算规则

验收假设 `H` 表示“该项已经真实完成且可交付”。

```text
后验赔率 = 先验赔率 × 每项独立证据的似然比
先验赔率 = P(H) / (1 - P(H))
后验概率 = 后验赔率 / (1 + 后验赔率)
```

证据强度：

| 证据 | 似然比 | 规则 |
|---|---:|---|
| 只有执行者口头汇报 | 1 | 不更新概率 |
| 代码定位 + 针对性自动测试通过 | 4 | 必须记录文件、测试名和原始结果 |
| 本地 API 集成测试通过 | 6 | 必须使用真实 HTTP 边界或受控 mock server |
| Playwright 完整点击路径通过 | 6 | 必须保存截图、DOM 断言和控制台结果 |
| 安全泄漏扫描 + 负向攻击测试通过 | 8 | 仅用于密钥安全项 |
| 独立审查者复跑并通过 | 5 | 不得复用开发者结论 |
| 真实供应商财务接口脱敏验证通过 | 10 | 只能保存脱敏结果，不保存密钥 |
| 发现反例、缺证或结果冲突 | 0.05 | 立即回退为不通过并修复 |

同一测试重复运行、同一截图的不同描述、同一实现者的多次自述属于相关证据，只能计算一次。

### 验收维度

| 编号 | 验收假设 | 先验 P(H) | 权重 | 硬门禁 | 最低后验 |
|---|---|---:|---:|---|---:|
| B1 | 左侧二级导航、路由、默认跳转和移动端行为正确 | 0.20 | 15% | 是 | 0.95 |
| B2 | 基础设置与成本设置归属正确且无重复管理入口 | 0.20 | 15% | 是 | 0.95 |
| B3 | 使用统计已删除独立“按来源拆分”且其他统计未回归 | 0.20 | 10% | 是 | 0.95 |
| B4 | API Key 安全存储、传递、删除和脱敏不存在明文泄漏 | 0.10 | 20% | 是 | 0.99 |
| B5 | 供应商财务接口只查询余额/花销且状态语义真实 | 0.10 | 15% | 是 | 0.95 |
| B6 | 成本设置与成本累积完成端到端数据闭环 | 0.20 | 15% | 是 | 0.95 |
| B7 | 全量测试、构建、Tauri 和既有功能无回归 | 0.70 | 10% | 是 | 0.95 |

最终通过条件：

- B1-B7 全部达到最低后验。
- 加权总后验不低于 0.95。
- B4 不低于 0.99。
- 没有未关闭的 P0/P1 问题。
- 没有真实供应商凭据时，B5 只能标记“待用户凭据验收”，不得宣称正式上线通过。
