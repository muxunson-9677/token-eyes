# 01 - 二级导航与页面重构

## 中文简述

本工单只负责前端信息架构：把支出和设置拆成左侧导航二级模块，移动现有设置区块，删除使用统计中的独立“按来源拆分”。不实现供应商 API 后端，也不伪造余额数据。

## 第一性原理执行规则

- 页面入口必须反映用户任务，而不是用一个大页面和临时 state 隐藏多个功能。
- 二级模块必须有独立 URL，刷新、深链、前进后退和移动端点击都应保持正确页面。
- “成本设置”负责配置，“成本累积”负责查看结果和管理订阅记录，不能混为同一页面。
- 删除模块时只删除独立“按来源拆分”，不得误删 Provider 统计、模型统计或请求日志筛选。
- 只做本工单需要的外科式修改，不顺手重构其他页面。

## 目标

实现以下左侧导航：

```text
概览
支出
  使用统计
  成本累积
设置
  基础设置
  成本设置
```

## 必做任务

### 1. 建立独立路由

- `/spend/usage`：使用统计。
- `/spend/cost`：成本累积。
- `/settings/basic`：基础设置。
- `/settings/cost`：成本设置。
- `/spend` 使用 replace 重定向到 `/spend/usage`。
- `/settings` 使用 replace 重定向到 `/settings/basic`。
- Tauri 根入口改为 `/settings/basic`。
- 更新 `dashboard/src/App.jsx` 中基于精确字符串的路径判断，确保子路由被识别为 dashboard 页面并显示 Sidebar。

### 2. 左侧导航二级结构

- 修改 `dashboard/src/ui/components/Sidebar.jsx` 的导航数据结构和渲染。
- 父项显示图标和展开状态，子项显示文本层级。
- 当前位于任一子路由时，父项和对应子项都显示选中状态。
- 点击父项：展开子项并进入默认子路由；再次点击不得让当前页面消失。
- 桌面侧栏与移动端 Drawer 使用同一导航数据和相同行为。
- 键盘可聚焦，展开按钮具有 `aria-expanded`，子导航具有可识别标签。
- 切换语言后父项和子项文案同时更新。

### 3. 拆分支出页面

- 移除 `SpendPage.jsx` 中页面顶部的 `activeSpendTab` 和一级 Tab UI。
- `/spend/usage` 只渲染使用统计内容。
- `/spend/cost` 只渲染成本累积内容。
- 保留成本累积已有 Token 套餐状态、API 计费占位/结果和订阅记录区域，后续由 03 接入新后端。
- 保留使用统计中的 Provider 统计、模型统计和请求日志三个页签。
- 删除标题为“按来源拆分”的独立表格及仅为该表格服务的前端 state/派生数据。
- 删除后不得影响 Provider 可见性过滤和成本汇总 API。

### 4. 拆分设置页面

- `/settings/basic` 渲染：`AppearanceSection`、`MenuBarSection`、`AccountSection`、`DataDirectoriesSection`、`AgentPricingSection`、限制显示及 `NativeAppFooter`。
- `/settings/cost` 渲染：`TokenPlanSection`，并为 03 的 `ProviderApiConfigSection` 留下明确组件插入位置。
- `TokenPlanSection` 不得继续出现在基础设置。
- 不复制组件形成两个管理入口。
- 页面标题、副标题和 copy 必须表达当前子模块，新增文案进入 copy registry，不硬编码用户可见中文。

## 明确禁止

- 不实现或修改供应商 API 请求逻辑。
- 不存储 API Key。
- 不删除 Provider 统计页签。
- 不把四个子页面重新做成同一页面内的视觉 Tab。
- 不使用 URL hash 或仅存在于 React state 的伪路由。
- 不改概览页、同步解析器、定价算法和发布 workflow。

  - 在 NavParent.handleClick 末尾增加 onItemClick?.() 调用（桌面端 onItemClick 为 undefined，no-op；移动端关闭抽屉）
  - 更新 useCallback 依赖数组加入 onItemClick
