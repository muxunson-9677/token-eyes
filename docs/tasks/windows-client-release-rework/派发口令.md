## 执行顺序

```text
先并行：
R1 || R2

再串行：
R3

再串行，建议复用 R3 上下文：
R4

最后全新独立上下文：
R5
```

## 上下文规则

- R1 和 R2：必须不同上下文、不同 worktree，可并行。
- R3：主线集成上下文，不能和 R1/R2 的脏工作区混用。
- R4：可复用 R3 上下文，因为它是主线完成前审查和最小合流修复。
- R5：必须新建全新上下文，不能复用 R1-R4，不能参与修复。
