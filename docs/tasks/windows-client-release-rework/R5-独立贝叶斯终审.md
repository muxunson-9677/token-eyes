# R5 - 独立贝叶斯终审

## 目标

由未参与 R1-R4 的全新上下文，独立复验发布 HEAD、安装包内容、真实签名、依赖安全、干净 Windows 安装和数据闭环，重新计算 B1-B7 后验。只有全部硬门禁通过时，才允许结论为 `可外部安装验证`。

本工单不自动授予正式上线结论；正式 release 仍需用户明确批准。

## 独立性硬门禁

- 审查者不得执行过 R1、R2、R3、R4。
- 审查者不得参与本轮修复决策。
- 审查者不能只读完成报告；必须亲自运行命令、检查产物和验证干净环境。
- 若 R5 发现问题，该上下文只能写 `RETURNED`，不得修复后自行签发。
- 修复完成并重跑 R4 后，必须新建另一个全新 R5 上下文。

## 第一性原理执行规则

1. 默认安装包不可用，直到独立证据逐项否定反例。
2. 数值后验不能覆盖硬失败。
3. 任一 P0/P1、缺证、输出冲突直接不通过。
4. 同一测试、同一截图、同一安装包清单不能重复计 LR。
5. 无真实签名证书、无真正干净 Windows、无最终产物时只能 `BLOCKED`。
6. 不读取或保存用户提示词、消息正文、API Key、Cookie、令牌、`.env` 值。
7. 最终结论只能是：`不可外发`、`BLOCKED`、`可外部安装验证`。

## 必须重新攻击的反例

### R5.1 HEAD 与构建输入

- 从最终 HEAD 创建新的干净 checkout/worktree。
- 验证生产代码、runtime script、workflow、测试和工单已跟踪。
- 不复制原工作区 `dist`、`target`、EmbeddedServer 或未跟踪源码。
- 重新安装依赖并构建。

### R5.2 自包含 runtime

- 解包最终 MSI/NSIS。
- 独立检查 Node、CLI、Dashboard、生产依赖、manifest、license。
- 在 PATH 无 Node、cwd 不在 repo、无旧服务环境启动。
- 通过进程路径证明使用安装目录内 bundled `node.exe`。

### R5.3 本地 API / 同步 / 恢复

- 验证 `/api/local-auth` 协议、capabilities 和三个核心端点。
- 使用 fixture 连续同步两次，第二次不得重复计数。
- 验证至少一个真实 Agent 本地日志计数，不读取消息正文。
- 杀后端、占用端口并重试，验证可见错误和恢复。

### R5.4 安全扫描

- 独立运行 root/dashboard production audit 和 cargo audit。
- 重建 `ws`、`quick-xml` 反向依赖链。
- 扫描源码、dashboard dist、安装包解包目录和日志中的密钥模式、`.env`、完整用户路径。

### R5.5 签名与发布资产

- 独立验证 EXE/MSI/NSIS 签名、发布者、时间戳、哈希。
- 篡改副本，证明签名校验失败。
- 检查 workflow glob、README 下载名、版本、SHA256SUMS 一致。

### R5.6 第二干净 Windows 生命周期

- 使用不同于 R3/R4 正常路径的全新快照或第二台干净环境。
- 验证首次启动、重启、重复启动、断网、本地历史数据、重装、卸载。
- 检查卸载后进程/安装目录，检查默认用户数据保留契约。

### R5.7 workflow fail-closed

- 静态检查 workflow 并运行 tests。
- 在受控副本/测试中制造 audit 失败、runtime 缺文件、版本不一致、签名无效，确认 upload 不执行。
- 检查 release draft 不会在 Windows/macOS 任一失败时提前公开。

## 产物验证

```powershell
$ReleaseRoot = (Resolve-Path "src-tauri\target\release").Path
$AppExe = Join-Path $ReleaseRoot "token-eyes.exe"
$Msi = Get-ChildItem (Join-Path $ReleaseRoot "bundle\msi\*.msi") | Sort-Object LastWriteTime -Descending | Select-Object -First 1
$Nsis = Get-ChildItem (Join-Path $ReleaseRoot "bundle\nsis\*-setup.exe") | Sort-Object LastWriteTime -Descending | Select-Object -First 1
$Artifacts = @($AppExe,$Msi.FullName,$Nsis.FullName)
$Artifacts | ForEach-Object { Get-AuthenticodeSignature $_; Get-FileHash $_ -Algorithm SHA256 }
if ($Artifacts.Where({ (Get-AuthenticodeSignature $_).Status -ne 'Valid' }).Count -gt 0) {
  throw "Independent signature verification failed"
}

$ExtractDir = Join-Path $env:TEMP ("token-eyes-r5-msi-audit-" + [guid]::NewGuid())
New-Item -ItemType Directory -Path $ExtractDir | Out-Null
$Process = Start-Process msiexec.exe -ArgumentList @('/a',('"' + $Msi.FullName + '"'),'/qn',('TARGETDIR="' + $ExtractDir + '"')) -Wait -PassThru
if ($Process.ExitCode -ne 0) { throw "MSI administrative extract failed: $($Process.ExitCode)" }
Get-ChildItem -Recurse -File $ExtractDir
```
