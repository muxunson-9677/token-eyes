```json
  "project_ref": "https://github.com/muxunson-9677/token-eyes"

```

**代码证据**: `src/lib/project-path.js` 第 134-136 行
```javascript
// 错误的修复：把远程 URL 当作 project_path 返回
if (typeof projectRef === "string" && projectRef.trim()) {
  return projectRef.trim();
}
```
