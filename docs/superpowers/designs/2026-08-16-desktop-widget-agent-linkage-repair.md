# DeepSeek Harness 与桌面小组件联动修复设计

## 背景

本轮修复处理五类已经在真实安装环境中出现的问题：

1. “限制显示”缺少 DeepSeek Harness。
2. 桌面小组件折叠后仍保留大面积空白。
3. 小组件页选择的文件夹与套餐没有按原选择完整显示。
4. “限制显示”、使用明细与小组件 Agent 菜单没有共享同一套可见 Agent 约定。
5. 特效关闭按钮距离主体过远，关闭特效时原生窗口发生闪烁和跳位。

历史核对表明，旧提交没有丢失。后续提交重新修改了项目过滤、套餐窗口归并和小组件原生几何持久化逻辑；同时，旧特效方案只覆盖“存在透明光晕”，没有锁定关闭前后的真实屏幕坐标，因此回归没有被现有测试拦住。

## 已确认的真实状态

- 正式开发工作树：`D:\04-AI-Project\010-Token eye\.worktrees\v4-ui-round-20260816`
- 分支：`codex/v4-ui-round-20260816`
- 当前工作树包含上一轮未提交 UI 调整，本轮只在相关文件上做外科式增量修改。
- 用户实际小组件偏好中，折叠高度被保存为 `260`；设计基准应固定为 `72` 逻辑像素。
- 用户实际 `C:\Users\admin\.dsh\sessions` 中存在 `.jsonl.zstd` 会话文件，记录包含会话目录、模型与精确 Token 用量。
- 本轮继续遵守用户复核门禁：不提交、不推送、不合并、不打包。

## 方案

### 1. DeepSeek Harness 使用真实适配器

新增稳定 Agent id：`deepseek-harness`，队列来源同为 `deepseek-harness`。

数据来源按 DeepSeek Harness 官方约定解析：

- 根目录优先级：`DSH_HOME`，否则 `~/.dsh`。
- 会话目录：`sessions/**/session.jsonl.zstd` 与显式未压缩 JSONL。
- 模型从 `request/context.data.model` 获取。
- Token 从 `assistant/chunk` 的 usage 样本与 `assistant/message.data.usage` 获取；同一 `(session, turn, step)` 的最终消息替换流式样本，避免重复计数。
- 输出、输入、缓存读取与推理 Token 保留真实字段，不估算、不伪造。
- 增量游标按文件和会话步骤累计值处理；文件未变化时不重复入队。

### 2. 三个界面共享可见 Agent 约定

`limits-providers.js` 继续作为“限制显示”的顺序与显隐正典；Agent 注册表负责把 id 映射到队列来源和显示名称。

- “限制显示”启用 DeepSeek Harness 后，使用明细 Agent 筛选可见。
- 桌面小组件 Agent 菜单只展示“限制显示”中启用且小组件支持的 Agent。
- 当前已选 Agent 被关闭时回退为“全部”，不保留不可见的陈旧选择。
- 已启用但暂无记录的 Agent 仍可选择，并显示真实空态。

### 3. 折叠高度成为固定不变量

- 折叠态高度固定为 `72` 逻辑像素，不再持久化用户拖动产生的折叠高度。
- 已存在的版本 7 污染配置（例如 `collapsedHeight: 260`）在读取时迁移回 `72`。
- 展开高度仍可持久化。
- 弹出菜单、外观面板与特效临时几何不写回基础尺寸。
- 折叠态原生窗口禁止调整大小，展开时才允许调整。

### 4. 文件夹与套餐忠实保留用户选择

- 已选择的文件夹即使当前没有活跃会话，也保留在小组件中并显示“暂无活跃会话”。
- 同一项目 id 的快照合并时，非空路径和明确标签优先，后续空路径不得覆盖已有路径。
- 一个套餐的 5h、7d、月度等额度窗口逐项展示，不再只取一个代表窗口。
- 套餐窗口保持稳定 id、用户选择顺序与官方重置时间；数据缺失时显示不可用，不借用另一窗口的数据。

### 5. 特效不再移动小组件主体

维持单窗口方案，但建立稳定几何握手：

- 特效打开时记录基础主体几何，透明光晕只扩展一次临时外框。
- 关闭按钮相对小组件主体右上角定位，而不是相对扩大后的透明窗口右上角定位。
- 关闭时先恢复原生基础几何，收到完成结果后再移除前端光晕类，避免中间帧闪烁。
- 设置尺寸与位置时先计算单一目标几何，并在同一命令调用中完成；任何临时状态都不触发 `persist_geometry`。
- 若真实原生核验仍出现跳位，才升级为独立覆盖窗口；本轮不提前引入第二窗口架构。

## 验收标准

1. DeepSeek Harness 出现在“限制显示”中，可启用、关闭和拖拽排序。
2. 启用后同时出现在使用明细 Agent 筛选与小组件 Agent 菜单中。
3. 真实 `.jsonl.zstd` 会话能生成 `deepseek-harness` Token 记录；重复同步不重复计数。
4. 折叠态在 100% 与 175% 缩放下均为 72 逻辑像素，无下方空白。
5. 已选但无活跃会话的文件夹继续显示，非空路径不会被空快照覆盖。
6. 同一套餐的 5h、7d 等窗口完整且顺序稳定。
7. 特效关闭按钮贴近主体；关闭前后主体的屏幕坐标和基础尺寸一致，不闪烁、不跳位。
8. 两轮独立核验：先逐条需求匹配，再使用真实原生小组件进行效果核验。

## 非目标

- 不改变其他 Agent 的解析语义。
- 不重构整个小组件或使用明细架构。
- 不修改套餐官方数据本身。
- 不在用户验收前提交、推送、合并或打包。
