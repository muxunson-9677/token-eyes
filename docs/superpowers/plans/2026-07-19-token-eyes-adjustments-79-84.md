# Token Eyes 调整项 79–84（对抗性修复记录）

> 作用域：仅 `D:\04-AI-Project\010-Token eye\.worktrees\provider-api`。禁止修改本项目以外的文件、软件和账号数据。
>
> 完成标准：每项必须有对应代码、回归测试或构建证据；“界面显示已连接”不能代替真实额度解析成功。

## 调整项

### 79. 修复 TRAE 图标

- 使用项目内置的稳定 SVG，不再依赖可能失效的远程 favicon。
- 概览、使用统计筛选和其他共用 `ProviderIcon` 的位置统一显示同一图标。
- 增加组件测试，防止以后重新引用远程或不存在的资源。

### 80. 缩小成本累积中的自定义花销卡片

- 分组卡片改为紧凑四列布局，减少内外边距、标题和数字尺寸。
- 保留本月、本年、总累积和记录数，不删除业务信息。

### 81. 修复 Cursor 额度持久化及 TRAE / CodeBuddy 数据目录发现

- Cursor 每个账号的授权凭据按独立账号引用持久化到 Token Eyes 应用数据目录，重启后仍可刷新真实额度。
- 额度保存优先使用官方返回的 `total_quota`，不再被套餐目录中的占位总额 `0` 覆盖。
- TRAE / CodeBuddy 在桌面端首次进入设置时自动发现真实用户数据目录并持久化；安装目录与日志目录分开处理。
- TRAE 纳入原生账号连接和刷新白名单，修复 `provider_id must be a supported console session provider`。

### 82. 删除 Token 套餐无意义的汇总额度

- 删除套餐模块顶部把不同单位、不同窗口相加得到的“总额度 / 已用额度 / 剩余额度”。
- 各套餐仍显示各自官方额度与窗口，避免把 credits、百分比和 requests 混加。

### 83. 固化 Token 服务列表过滤和排序规则

- 过期套餐不显示；只有一个官方滚动窗口时，窗口重置/有效时间已过也视为过期。
- 第一优先级：未过期且仍可用，按已用量从大到小。
- 第二优先级：未过期但额度已用完，仍显示在可用套餐之后。
- 同一优先级保持稳定顺序；备注继续用于区分同供应商多账号。

### 84. 删除成本累积中的订阅记录明细块

- 保留顶部“本月订阅成本”汇总卡。
- 删除下方可增删改的“订阅记录”明细面板，避免重复入口和冗余占屏。
