## 4. 页面内容合同

### 4.1 价值对比页

#### 一级视觉中心

- 本月实际支出
- 本月使用价值（公开 API 价格等价折算）
- 价值倍数
- 辅助信息：已识别 Token、数据覆盖率

#### 二级信息

- 本月构成：订阅、API Key、积分/速通/配额、待识别
- 套餐价值对比：本月实付、使用价值、价值倍数、轻量趋势
- 最近六个月趋势：实际支出与使用价值

#### 三级折叠

- 订阅套餐与 API Key 详细对比
- 积分、速通、配额原始明细
- 模型价格与价格覆盖率
- 待识别与归因说明
- 官方账单、余额、本地估算
- 说明与数据状态

### 4.2 实时会话页

#### 一级视觉中心

- 当前活跃 Agent
- 实时 Token/Credits
- API 等价价值
- 当前焦点会话大卡

#### 焦点会话字段

- Agent 与真实状态
- 会话/任务/项目可读标识
- Token、Credits、次数或原生额度
- API 等价成本与最新真实增量
- 请求数、子 Agent、持续时长、模型、计费方式

#### 二级与三级信息

- 其他 Agent 紧凑摘要
- 会话构成
- 实时趋势
- 子 Agent
- 请求明细
- 数据状态
- 价格覆盖率
- 图例说明

### 4.3 供应商原生资源合同

| 供应商 | 页面主单位 | 允许的补充信息 | 禁止推断 |
|---|---|---|---|
| WorkBuddy / CodeBuddy | Credits / 积分 | 原始余额、已用量、变化量、快照时间、证据状态 | 固定 Credits/积分 → Token 或美元汇率 |
| Qoder | Credits | 已验证后才可单独展示 Token 能力；未验证时标明状态 | 未经专项验证便声称可获得精确 Token |
| Trae CN | 速通 / 快请求次数 | 剩余次数、已用次数、变化量、快照时间 | 固定次数 → Token 或美元汇率 |
| Trae 国际版 | USD 额度、已用百分比 | 总额度、剩余额度、快照时间 | 将额度余额当作实际现金支出或 API 等价价值 |

### 4.4 分阶段实施合同

以下阶段是依赖顺序，不得跳过基础合同直接堆叠 UI：

1. **P0：** 锁定信息架构、术语、数据合同与隐私白名单。
2. **P1：** 使用现有聚合数据完成价值对比 MVP，未知值保持未知。
3. **P2：** 接入 `plan_ref/account_ref` 套餐级归因；无证据数据保留在未归因层。
4. **P3：** 完成 Codex、Claude Code、Hermes 实时会话 MVP。
5. **P4：** 完成 WorkBuddy/CodeBuddy/Qoder/Trae 原生资源适配与状态降级。
6. **P5：** 仅依靠可靠父子证据完成多 Agent 根任务与子 Agent 树。

每一阶段都必须先补失败测试、实现最小真实链路、通过本阶段验收，再进入下一阶段；阶段拆分不能弱化本文档最终验收矩阵。
