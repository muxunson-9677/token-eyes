# 小组件套餐卡片与悬浮层修正实施计划

> 本轮明确不调整悬浮小组件整体宽高与长宽比例。

## 验收要求

1. 小组件页套餐卡片不显示订阅金额；重置时间右对齐；卡片按内容收紧且同一行等高；左上角拖拽手柄可以实时改变套餐顺序。
2. 悬浮小组件右侧三个模式按钮保持现有位置和尺寸，只修正与主胶囊的衔接质感。
3. Agent 菜单打开时切换主卡片展开/折叠，原生窗口仍为菜单保留完整高度，菜单不被裁切且主组件不跳动。
4. 悬浮小组件套餐折叠态只显示首个套餐汇总；展开态按套餐分卡，套餐名为主标题、账号为次要信息，同一套餐的多个额度窗口集中展示。
5. 展开态额度文案使用紧凑格式：`Weekly`、`2d 16h（08/20 11:33）`、`有效期 14 天`。

## 实施顺序

1. 先补充失败测试，覆盖拖拽、卡片内容、分组结构、紧凑时间和弹出层高度保持。
2. 以最小改动修复 React 结构、样式与 Tauri 窗口过渡逻辑。
3. 运行定向测试、类型检查和构建。
4. 按参考图触发的双审机制核对：一审逐条比对要求，二审检查真实渲染和完整交互旅程。
