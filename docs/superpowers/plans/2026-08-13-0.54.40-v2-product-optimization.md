# Token Eyes 0.54.40-V2 产品全量优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `0.54.40-V2` 分支上，将 Token Eyes 从"功能齐但不够精"升级为"简单、高效、精准、体验好、可传播"的个人开发者 AI 记账本，落地三个用户新增需求（套餐行情目录 / 订阅回本倍数 / 消息级 Token 明细）并纳入全部既定优化方向。

**Architecture:** 保持现有三层结构不变——CLI 本地 API（`src/lib/local-api.js`，CommonJS）做数据与计算，Dashboard（React 18 + Vite，`dashboard/src/`）只做展示，`queue.jsonl` 半小时桶为数据脊柱。新能力全部以"新增数据文件 + 新增端点 + 新增页面/卡片"方式增量接入，不改动现有解析器语义。

**Tech Stack:** Node ≥20 CommonJS（src/）、React 18 + Vite 7 + TS strict + Tailwind（dashboard/）、Vitest（dashboard 测试）、node:test（根测试）、html-to-image（分享卡）。

## 0. 战略背景（为什么做这些）

### 0.1 定位与时间窗口

- **生态位**：「所有 AI 工具 × 所有平台 × 本地优先 × 界面好看」的交集，目前市场为空。ccusage 占 CLI 报表（无 GUI）、Claude Code Usage Monitor 占实时终端（仅 Claude）、Grafient/CostLayer 占团队 API 账单 SaaS（不管订阅制额度）、国内工具全是单一工具/终端/macOS-only。
- **时间窗口**：2026 年 Anthropic 官方承认"用户额度耗尽速度远超预期"，缓存 bug 曾导致成本虚增 10–20 倍，额度焦虑是开发者头号痛点——第三方监控是刚需。
- **一句话价值**：回答三个问题——**我花了多少钱？还剩多少额度？什么时候会用完？** 所有页面与控件以此过筛。

### 0.2 设计原则（苹果五原则）

1. **开箱即用**：安装后自动扫描本机 AI CLI、自动接入、30 秒内看到自己的真实数据，零配置提问。
2. **做减法**：不新增导航负担；工具类页面（IP 检查等）收纳降级；每个新功能必须能回答三大问题之一。
3. **一套设计语言**：全站只用 `styles.css` 的 token 变量（`--oai-*`、`--radius-*`、语义色），禁止散装样式。
4. **可瞥视性**：托盘/菜单栏不打开主窗口即可获得今日花费/额度百分比。
5. **隐私即品牌**：本地优先、只存 token 数、绝不上传对话内容，作为营销第一句话。

### 0.3 不做清单（防臃肿硬约束）

- ❌ 社区/评论/私信/UGC（规避国内审核）
- ❌ 微信/手机号登录（邮箱 + Google/GitHub OAuth 已具备，不再投入）
- ❌ 团队版（个人版跑通前不做）
- ❌ API 网关/代理/模型路由
- ❌ 需要用户上传 API key 到云端的任何功能
