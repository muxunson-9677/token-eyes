## 数据与业务不变量

### 实际支出

- 同一所选自然月必须只有一套实际支出口径。
- 顶部实际支出等于所选月份已知支出类别之和；未知类别不得假设为 `$0.00`。
- 月订阅在一个自然月中只计一次，不能因 `Asia/Shanghai` 到 UTC 的边界转换重复计入相邻月份。
- `0`、未录入、无法读取和部分已知必须保持不同状态。
- 月份构成不得把 7 月金额当成 8 月金额参与 8 月构成；历史回退只能作为明确的历史提示，不能混入当前月合计。

### 六个月趋势

- 每个柱组代表一个自然月，而不是把周桶再按月份字符串拼接。
- 月订阅在每个月只出现一次；一次性支出只进入其发生月份。
- 当前月可以是尚未结束的月份，但不能把跨月总额平均摊到若干周后冒充当月支出。
- 趋势最后一个月的使用价值应与顶部同口径的所选月份使用价值一致。

### 套餐价值对比

- “本期实付”列只显示货币金额或账单未录入状态，不能显示 Token 数量。
- Token 用量可以作为来源旁的辅助证据，但不得占用货币列。
- 有真实实付且有可读价格时才计算价值倍数；任一侧缺失时显示对应的缺失状态。

### API 等价值

- 保留 0.54.47 已有的自定义价格规则，不修改用户的 `gpt-5.6-sol` 价格配置。
- 使用价值继续遵循当前项目的“本机 Token × 已配置价格”口径，并明确标示为估算或部分数据；不能伪装为供应商真实账单。
- 缓存 Token 的计价方式不得在本次任务中悄悄改变，以免影响 0.54.47 其他成本页面。

## 变更边界

允许修改：

- 【价值对比】和【实时会话】页面组件、专属样式和专属测试。
- 为修复上述不变量所需的价值对比本地接口与聚合帮助函数。
- 与最终 Windows 0.54.48 构建、运行时清单和安装验收直接相关的文件。

禁止修改：

- 0.54.47 既有页面的业务逻辑、权限、授权流程和视觉样式。
- 用户的真实账单、套餐、价格规则、队列、OAuth 状态和登录信息。
- 新建纠偏分支、切换分支、合并、变基或清理现有工作树文件。
