## 1. 项目边界

- 所有代码、配置、测试、文档和构建产物只能位于 Token Eyes 仓库及其项目工作树内。
- 不修改、启动、停止、安装、卸载或重新配置 CC Switch 以及任何项目外软件。
- Cockpit Tools 和生财有术只作为用户提供的视觉与信息层级参考，不复制其业务内容、账号数据或实现代码。
- 本地功能继续免登录；排行榜参与、上榜与云同步继续使用微信登录。

## 3. 第一性原理与统一口径

### 3.1 中文 Token 计量

Token 数值展示使用一个纯函数作为唯一规则：

- `0–9,999`：显示本身，例如 `8560`。
- `10,000–9,999,999`：使用“万”，例如 `415.6万`。
- `10,000,000–99,999,999`：使用“千万”，例如 `3.28千万`。
- `100,000,000` 及以上：使用“亿”，例如 `33.16亿`、`1043.37亿`。
- 最多保留两位小数并去掉无意义的末尾零。
- 金额、请求数、参与人数、百分比不使用这个函数。

### 3.2 排行榜信息层级

排行榜的核心任务是快速比较“谁、用了什么、共消耗多少”。因此取消表格中的独立 Agent 大列，改为紧凑列表行：

1. 左侧窄序号，前三名保留低饱和奖牌色。
2. 中间为头像与用户名称；下一行用灰色小字显示该用户实际使用过的 Agent 及各自用量。
3. 右侧显示当前口径总量，次级灰字显示预估花销。
4. 行高控制在桌面约 76–88px；Agent 过多时换行但不单独占用 34% 页面宽度。

侧栏已经承担返回功能，所以桌面 Token Eyes 内移除标题区“返回概览”；公开网页仍可使用浏览器导航，规则入口保留。

### 3.3 Token 服务卡片

每条服务以“服务商账户/套餐的运行状态”为一个交互单元：

- 标题：供应商图标 + 供应商名称；同一行或下一行显示灰色套餐名称。
- 主额度：进度条、已用、总量和占比。
- 多窗口额度：5 小时与周额度分别形成两行，不用一个窗口覆盖另一个窗口。
- 时间：套餐到期显示“有效期至”；动态窗口显示“重置于”。
- 状态颜色只承担风险含义：正常绿色、接近耗尽橙色、耗尽红色。

### 3.4 设置折叠与目录覆盖

折叠只改变展示，不延迟或伪造配置能力。目录注册表是单一来源，UI、自动检测、单项检测和同步解析必须使用同一组键。Antigravity 默认与 Gemini 共用 `~/.gemini` 根目录，但允许单独覆盖；这在界面文案中明确说明。

### 3.5 视觉原则

- 视觉论点：冷白/深灰的雾面工作台，低对比卡片分层，单一品牌绿色作为选中与成功状态。
- 内容计划：页面标题与筛选 → 关键汇总 → 主工作列表/图表 → 次级说明。
- 交互论点：选中项使用轻底色和内描边；折叠使用 160–200ms 高度/箭头过渡；进度变化使用短过渡。禁用装饰性大动画。

采用渐进式语义重构，不采用以下方案：

- 不整页照搬 Cockpit Tools：会把账号管理内容错误带入 Token Eyes。
- 不进行全局设计系统重写：范围过大，会使本轮七项问题难以独立验证。

### 3.6 启动性能根因假设

当前静态 `index.html` 已有启动占位，但 `createRoot()` 后的首个 `Suspense fallback={null}` 会立即清空占位；Tauri 根路由随后重定向到懒加载的 `/settings/basic`。此外 `SettingsPage.jsx` 同时静态引用成本设置的大组件，使首个基础设置路由仍需解析与基础设置无关的依赖。此前只测 Windows 窗口句柄和 `Responding`，因此把“空窗口已响应”误判成“页面可用”。

修复策略：

1. React 首路由加载期间使用与静态 HTML 一致的启动界面，禁止空白 fallback。
2. 将成本设置依赖改为仅进入 `/settings/cost` 时加载，基础设置首路由不请求 TokenPlan/供应商 API/其他 AI 花销块。
3. 测试同时检查静态占位、非空 Suspense fallback 和路由依赖边界。
4. 自动基准继续测进程窗口；覆盖安装后的首屏内容体感由用户最终验收，不能再用 `Process.Responding` 冒充。

## 4. 对抗性验收清单

- 排行榜 Agent 数为 0、1、多个时均不产生空列；长用户名和多个 Agent 不覆盖右侧总量。
- 中文单位覆盖 9,999、10,000、9,999,999、10,000,000、99,999,999、100,000,000 以及负值/空值边界。
- Token 服务覆盖单额度、5 小时 + 周额度、100% 耗尽未过期、刚过期、无到期日、同步失败和未配置。
- 目录注册表与限制显示注册表集合相等；新增目录值保存后同步解析读取同一键，不允许仅增加输入框。
- 折叠按钮支持键盘和屏幕阅读器，展开状态通过 `aria-expanded` 暴露。
- 所有选中态不只依赖颜色，至少同时具备底色/描边/阴影中的两种。
- 启动契约必须在修复前失败、修复后通过；生产构建记录首包及基础设置路由相关 chunk 大小。

## 5. 汇报规则

每完成一个可独立验证的事项，更新本文状态并汇报：本次完成、验证结果、仍未完成、下一步。最终交付新的仓库内 NSIS 安装包，但不自动覆盖安装系统客户端。
