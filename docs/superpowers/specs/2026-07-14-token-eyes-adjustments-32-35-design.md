## 3. 数据设计

### 3.1 Token 套餐删除

为现有 Token 套餐端点增加 `DELETE`。请求体只接受本地套餐 `id`。后端原子删除套餐记录，并清理仅由该套餐引用的本地密钥；不会取消供应商订阅、删除供应商账号或修改其他软件。不存在的记录返回 404，重复删除不会误删其他套餐。

### 3.2 供应商余额适配器

采用供应商专用适配器，而不是一个通用 URL/Key 表单：

- Kimi：官方 Bearer API Key 余额接口。
- 阿里云：BSS `QueryAccountBalance`，AccessKey ID/Secret，最小只读财务权限。
- 火山引擎：费用中心 `QueryBalanceAcct`，AccessKey ID/Secret，最小只读财务权限。
- 智谱、Xiaomi MiMo、MiniMax：独立官方控制台授权窗口，同源读取官方财务数据；只允许官方域名；余额同步成功后自动关闭授权窗口。

任何凭据只进入本机安全凭据存储。配置、日志和前端持久化状态只保存不可逆引用与脱敏结果。

### 3.3 其他 AI 花销

在本地配置中新增：

- `otherAiSpendGroups`: `{ id, name, sort_order, created_at, updated_at }[]`
- 花销记录新增 `group_id`、`favorite`、`sort_order`

“未分组”是虚拟分组，不持久化为可删除记录。编号根据“分组顺序 + 组内条目顺序”实时生成，不作为业务主键。收藏只用于视觉强调和筛选，不自动改变用户排序。

### 3.4 分组成本

后端汇总同一批 `source=other_ai` 记录，输出每组：

- `month_usd/cny`
- `year_usd/cny`
- `lifetime_usd/cny`
- `record_count`

一次性花销按发生日期计入对应月份和年份。未来日期不提前计入。总成本继续包含其他 AI 花销，但 API 与订阅分类保持互斥。

## 4. UI 设计

- 一级区块标题承担类别、数量、核心小计、添加操作和整体折叠。
- 二级列表行只显示编号/拖拽柄、名称、关键金额或余额、状态、收藏、编辑/删除和展开箭头。
- 详细字段、检测凭据、备注和次要操作只在单条展开后出现。
- 删除是危险操作，使用红色次级按钮和明确对象名称的确认提示。
- 卡片层级保持冷灰工作台、白色主面板、轻阴影与清晰选中态；不把每段文字都做成等权重卡片。

## 5. 对抗性验收

- 删除一个套餐不影响其他套餐、共享会话、供应商账户或项目外文件。
- 余额为真实 `0` 时显示 0；未授权、接口变化或缺少权限时显示错误，绝不伪造 0。
- 分组删除、改名、重排后条目不丢失；非法 group ID 自动回到未分组。
- 拖拽失败或刷新页面后顺序不会回跳；编号无重复、无跳号。
- 收藏切换后金额、分组和顺序不改变。
- 月、年、累计分组之和与原始记录在同一汇率口径下完全一致。
- 所有新增文案进入 copy registry，不在 JSX 中硬编码。
