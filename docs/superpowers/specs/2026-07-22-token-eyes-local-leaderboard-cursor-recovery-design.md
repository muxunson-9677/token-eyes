# Token Eyes 本地排行榜与 Cursor 恢复设计

## 目标

修复 0.54.8 中 Cursor 套餐刷新误报授权失效的问题，并按用户确认的产品口径调整 Token 套餐、环比颜色和排行榜即时展示。改动仅限 Token Eyes 当前仓库，不迁移、不删除用户现有数据。

## Cursor 刷新

当前本机 Cursor 授权文件、套餐绑定和会话编号仍然一致，失败发生在刷新流程：每次查询用量前都强制刷新令牌，刷新接口拒绝时直接标记为重新授权，即使现有访问令牌仍有效。

修复后先使用已保存的访问令牌查询官方用量。仅当官方用量接口明确返回未授权时，才调用刷新令牌接口并重试一次。网络错误、响应格式变化和额度解析错误不得被错误标记为登录失效，也不得删除现有授权文件。

## Codex 重置展示

删除每个 Codex 套餐卡片外部独立占位的“重置监控”面板。继续保留：

- 套餐详情中的额度窗口和重置时间；
- 侧栏醒目通知、托盘状态和重置事件检测；
- 原有后台检测频率与免费实现。

## 环比颜色

成本和用量模块的环比数字恢复为绿色。上涨、下降都使用原有绿色视觉；无变化继续使用灰色。计算逻辑保持当前已校正的实现，不回退低基数保护和数据口径。

## 排行榜即时本机行

公共排行榜始终显示其他用户。邮箱登录后，客户端立即读取本机紧凑统计，把当前用户作为“我的数据”插入当前榜单页面，以便与其他用户比较，不等待云端日更聚合。

本机行遵循当前筛选条件：今日、本周、本月、总累计，以及全部或单个工具。它使用本机 token 统计生成总量和工具拆分；可用的本机实际成本继续遵循用户的公开勾选。正式云端个人行到达后，按用户 ID 去重并替换临时本机行，绝不显示两条“我”。没有正式云端名次时显示“待更新”而不是伪造排名。

云端每日刷新仍保留，用于让其他用户看到该用户数据并产生正式名次；本机即时展示不改变上传内容、隐私边界或公开排行榜读取权限。

## 错误处理与验证

- Cursor 增加“有效访问令牌不应因刷新失败而失效”的回归测试，并验证真正未授权时仍会刷新和重试。
- Token 套餐测试确认独立重置监控面板不再渲染，但套餐重置时间仍存在。
- 环比测试确认上涨和下降均为绿色，同时保留低基数计算断言。
- 排行榜测试确认登录后本机行立即出现、公共行仍存在、筛选正确、云端个人行会替换本机临时行。
- 通过相关 Node、Dashboard、Rust 测试后构建新的 Windows NSIS `.exe` 安装包。

## 非目标

不删除云端排行榜，不改登录方式，不增加 X 搜索，不改刷新收费策略，不清空或重建用户套餐、API、Cursor 授权及历史 token 数据。
