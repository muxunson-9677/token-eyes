# Token Eyes 产品修正设计

日期：2026-07-22

## 目标

在 0.54.6 已确认可用的产品基础上修正 0.54.7 新增功能与既有功能的交互问题，不覆盖、不重做旧项目功能，不改仓库之外的文件。

完成后应满足：

1. 未登录用户仍可使用全部本地功能并查看排行榜；登录入口只出现在排行榜。
2. 正式安装版始终连接自身安装包携带的本地后台，不能误接旧工作区或其他版本服务。
3. 成本累计的明细模块可折叠，列表增长后仍易浏览。
4. 已连接的 Codex 套餐在应用运行期间自动刷新，并显示快照时间与重置时间。
5. 登录排行榜后立即上传当前本地汇总、生成榜单结果并显示本人；失败必须可见且可重试。
6. 用户可见品牌统一为 Token Eyes；内部兼容接口、存储键和历史目录名保持不变。
7. Token 套餐本身记录购买/订阅时间、计费周期、金额和币种，且与“其他 AI 花销”不重复计费。
8. 成本统计口径、筛选、币种换算和环比表达一致且可解释。

## 设计决策

### 登录位置

从基础设置移除整个登录卡片。排行榜保留登录、注册、昵称、头像和实际成本公开设置。退出登录和资料编辑也放在排行榜范围内，避免基础设置再次出现账号入口。

### 供应商 API 后台隔离

已验证本地保存的 DeepSeek、火山引擎和阿里云凭据均可正常解密，并可用当前代码成功查询。故不迁移、不删除、不要求用户重填密钥。

正式构建不得扫描并复用任意 `Token Tracker` 本地服务。Tauri 只能复用本进程已经启动并持有的子进程；否则从安装包内启动新的 EmbeddedServer。开发构建仍可保留开发服务复用能力。前端不再把任意附近端口当成正式安装版后端。

本地健康握手增加构建版本和产品来源字段。正式客户端只有在版本及来源匹配时才接受服务地址。测试覆盖旧开发服务占用附近端口时仍启动并使用安装包后台。

刷新和测试连接继续返回供应商的真实状态；凭据缺失、鉴权失败、接口不支持和网络失败分别显示，不互相冒充。

### 成本模块折叠

成本总览保持展开。Token 套餐、供应商 API、API 计费、订阅记录和其他 AI 花销使用统一折叠标题；默认展开状态保持当前主要内容可见，用户切换状态后在本机记忆。

### Codex 套餐自动刷新

取消原生 Codex 会话被强制写成 `manual` 的行为。应用启动、窗口重新获得焦点及定时器到期时刷新已连接套餐；同一账户请求去重，失败保留最后一次成功快照并显示陈旧状态。轮询仅在应用运行时进行，不安装系统服务、不申请权限、不产生云端费用。

### 排行榜首次显示

参与同步以当前登录账户为作用域。首次登录或进入排行榜时：

1. 确认排行榜公开状态；
2. 读取本地隐私压缩汇总；
3. 上传当前账户的设备状态；
4. 触发一次轻量榜单生成；
5. 重新读取榜单与本人排名。

任何步骤失败都在排行榜显示同步状态和重试按钮，不再只写控制台。日常榜单仍按每天一次的免费计划刷新；首次登录的单次即时刷新用于保证用户立刻看到自己。

### 品牌清理

界面、页脚、分享卡片、登录提示和设备显示名称中的旧项目品牌统一改为 Token Eyes。为了保留 0.54.6 数据及云端兼容，`tokentracker-*` 接口路径、本地目录、数据库表和 localStorage 键不重命名，也不作为用户可见文字展示。

### Token 套餐成本单一来源

Token 套餐增加：记录创建时间、更新时间、订阅开始/结束时间、计费周期、金额和币种。套餐卡显示订阅时间、额度重置时间和最后同步时间。

套餐成本直接参与成本台账计算，不额外复制成 `spendRecord`。其他 AI 花销用于非套餐支出；新增或编辑时若与套餐的日期、金额、币种及归一化名称完全重复则阻止保存并提示去套餐处维护。

现有历史花销不做猜测性删除。既有套餐缺少金额时显示“未设置”，创建/更新时间按迁移时安全补齐；已存在的历史一次性花销继续保留，只有明确完全重复的数据才提示用户处理。

### 成本审计与环比

成本汇总请求必须携带与明细一致的来源筛选。币种换算使用后端同一汇率口径，不再由前端单独写死。当前月比较上月同日至今，历史完整月比较上一个完整月。

成本上涨使用警示色、下降使用绿色。当上月基数过小或百分比超过 999% 时，界面优先显示绝对差额和“上月同期基数较低”，不展示夸张但缺乏解释的四位数百分比。零基线、缺失数据和真实零值严格区分。

## 数据与隐私

- 不上传代码、对话、项目名、Skill、MCP、文件内容或按键数据。
- 排行榜仅上传已有压缩统计字段。
- API Key 保持 Windows DPAPI 加密存储，不进入日志、错误、配置或测试快照。
- 所有迁移为向后兼容的字段补充，不覆盖用户现有 Token 服务列表和历史成本数据。

## 验证标准

- 单元测试先复现每个根因，再实现修复。
- 供应商 API 用模拟签名契约测试覆盖 DeepSeek bearer、火山 HMAC、阿里云 RPC；本机只读实测三家均成功。
- 排行榜测试覆盖首次登录即时出现本人、账户切换、上传失败提示和重试。
- 成本测试覆盖筛选、汇率、时间边界、重复阻止和低基数环比。
- Codex 测试覆盖启动、焦点、定时刷新、请求去重和失败保留快照。
- 完成 dashboard、Node、Rust 测试与 Windows NSIS 构建，最后以覆盖安装验证数据保留。
