# Token Eyes 概览、成本与设置视觉修复设计

日期：2026-07-30

目标版本：0.54.34

方案状态：三项均经用户选择 A 确认

## 1. 目标

修复 0.54.33 在用户实际安装窗口中的三类体验问题：

1. 概览页左栏内容过少，产生大块空白，双栏关系失衡。
2. 使用统计成本卡的月度环比被拆成单独一行，统计图标位置不符合信息层级。
3. 成本累积、基础设置和成本设置缺少可扫描的图标与颜色层次，页面显得干燥。

交付标准不是单个组件或页面测试通过，而是 0.54.34 安装包在接近用户实际窗口尺寸、真实本地数据和完整页面导航下具有合格体验。

## 2. 视觉原则

- 恢复紧凑、稳定的工具型双栏。
- 颜色只用于区分模块、数据类型和状态，不作为装饰背景。
- 图标只帮助快速扫描，不增加无功能的按钮或交互。
- 保持白色主表面和现有视觉体系，不制作大面积彩色卡片墙。
- 不改变现有数据来源、计算逻辑、页面功能或交互路径。

## 3. 概览页布局

采用已确认的 A 方案，恢复 0.54.33 之前的双栏分工：

- 左栏：`StatsPanel`、`TrendMonitor`、`ModelUsageDonut`，以及原本属于左栏的本地提示、组件引导和安装提示。
- 右栏：`UsageOverview`、`DataDetails` 和截图分享区域。
- 维持现有 `lg:grid-cols-12`、左四栏／右八栏比例，不引入新的响应式断点或第三栏。
- `TrendMonitor` 与 `ModelUsageDonut` 必须位于左栏并连续排列，填补当前左栏大块空白。
- 截图模式与现有分享行为保持不变。

验收重点：

- 在约 1115×810 的安装窗口中，左栏不再只显示一张顶部卡片。
- 左右两栏从上到下都有连续内容，不出现当前截图中的整列空白。
- 页面滚动顺序、数据明细和现有功能没有被重新组织。

## 4. 使用统计的环比与统计图标

### 4.1 月度成本环比

四张成本摘要卡恢复完整环比文案：

- 示例：`较上月新增 913.7%`
- 减少时显示既有“较上月减少”文案。
- 持平时显示既有持平文案。

排版规则：

- 紧凑人民币金额与环比文案位于同一行。
- 环比使用更小字号，但必须完整可读，不只显示箭头和百分比。
- 不将环比拆成新的垂直行。
- 保持 `CNY` 的紧凑单位换算，避免全量数字挤压卡片。
- 该规则同时应用于使用统计摘要和成本累积顶部摘要，保证同一数据在两个页面的表达一致。

### 4.2 总请求数和总成本

- “总请求数”标题恢复为纯文字。
- 请求活动图标移动到请求数字前，与 `64,105` 组成同一数字行。
- “总成本”标题恢复为纯文字。
- 总成本数字已经含有 `$`，不再渲染额外的美元图标。
- 缓存命中率保持现有标题、百分比和进度条结构。

## 5. 成本累积视觉层次

采用已确认的 A 方案：彩色小图标配合克制白底。

### 5.1 顶部成本摘要

四张摘要卡使用语义一致的小图标和颜色：

- API 成本：蓝色活动／计费图标。
- 套餐成本：紫色套餐图标。
- 本月总成本：绿色成本图标。
- 累计总成本：橙色累计图标。

图标使用浅色小底块帮助识别，卡片主体仍保持白色。关键数据可继承对应语义色，但不能让四张卡同时高亮。

### 5.2 功能分区

`Token 套餐`、`供应商账户`、`API 计费`、`订阅记录` 等既有分区：

- 保留原有折叠、数量、刷新、添加和编辑行为。
- 分区标题前使用语义图标的小色块。
- 分区容器维持浅边框与白色主体，通过图标和间距建立层次。
- 不使用大面积彩色背景，不改变各分区的数据结构和业务顺序。

## 6. 基础设置与成本设置视觉层次

基础设置和成本设置使用与成本累积相同的彩色小图标语言。

### 6.1 基础设置

为现有主要分区提供语义图标：

- 外观：主题／外观图标。
- 菜单栏：窗口／菜单图标。
- 数据目录：文件夹图标。
- Agent 定价：定价图标。
- 限制显示：仪表／限制图标。

### 6.2 成本设置

为现有主要分区提供语义图标：

- Token 套餐：套餐图标。
- 供应商 API：连接／接口图标。
- 其他 AI 花销：花销图标。

### 6.3 组件规则

- 为共享 `SectionCard` 增加可选的图标与色调参数。
- 未传图标的既有调用保持当前表现，避免无关页面被连带修改。
- 图标仅出现在分区标题区域，不侵入表单标签和数据行。
- 不修改设置项、保存逻辑、折叠逻辑、API 配置或成本计算。

## 7. 明确不做

- 不修改 Token 统计、成本计算、汇率、请求数或缓存命中率的数据逻辑。
- 不调整限制显示、桌面小组件、排行榜、重置记录或其他已敲定页面。
- 不增加新按钮、新卡片、新设置项或新交互。
- 不重构无关组件，不统一改造项目中的所有卡片。
- 不改变 Agent、Provider、模型或项目的数据来源。
