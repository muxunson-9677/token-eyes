# Token Eyes 免费重置监控与每日排行榜设计

## 目标

- 排行榜仅在北京时间每天 23:55 刷新一次。
- Codex 实际额度变化尽可能接近实时检测，同时不产生云端调用费用。
- 官方公告优先覆盖 OpenAI 状态源与 Tibo（`@thsottiaux`）最近 48 小时的 Codex 重置相关帖子。
- 不启用自动付费、不上传本地代码、对话、项目名或其他隐私内容。

## 分层检测

### 1. 客户端额度检测

- Token Eyes 启动 10 秒后首次检查。
- 正常情况下每 2 分钟读取一次 Codex 额度摘要。
- 窗口重新获得焦点且最近 60 秒没有成功检查时立即检查。
- 失败退避为 2 分钟、10 分钟、30 分钟，避免离线或限流时持续请求。
- 只持久化额度百分比、重置时间和事件类型，不保存账户令牌或对话内容。

### 2. 签名公告源

- 客户端每 5 分钟拉取一次 InsForge 上的签名公告 JSON，使用 ETag；无变化时返回 `304`。
- OpenAI Status 的 Atom/JSON 官方公开接口每 5 分钟检查一次，不需要 API Key。
- Tibo 帖子通过 Tavily Basic Search 每小时查询一次，严格限定 `x.com/thsottiaux/status/<数字>`、Codex 关键词和最近 48 小时。
- Tavily 免费账户每月 1,000 credits；Basic Search 每次 1 credit。每小时一次最多约 744 credits/月。
- 不配置 Tavily 付费账户。额度耗尽或服务异常时只暂停 Tibo 搜索，本地额度检测和 OpenAI Status 继续工作。
- 搜索结果采用确定性规则分类，不调用大模型。免费模型不能替代网页搜索，且会增加误判与密钥维护。

## 公告安全

- 云端只发布标题、官方链接、作者、发布时间和事件类型。
- 只接受 OpenAI 官方状态链接或 `OpenAI`、`thsottiaux` 的精确 X 帖子链接。
- 发布前生成 Ed25519 签名；客户端验签失败时忽略新公告并保留尚未过期的旧公告。
- 同一帖子 ID 去重，超过 48 小时的 Tibo 帖子不再触发新提醒。

## 排行榜

- InsForge 定时表达式改为 `55 15 * * *`（UTC），即北京时间每天 23:55。
- 保留现有手动刷新和失败重试能力，不新增 GitHub Actions。
- 榜单显示最后生成时间；当天 23:55 前可能仍显示上一次快照，这是每日刷新方案的明确取舍。

## 验证

- 单元测试覆盖 2 分钟本地检查、5 分钟公告轮询、退避和 48 小时过滤。
- 验证公告源的 ETag、签名、允许列表与无密钥降级。
- 验证 InsForge 排行榜计划仅每日执行一次。
- 构建新的 Windows NSIS 安装包并核对 SHA-256。

## 用户侧前置条件

- 排行榜与本地重置检测无需用户配置。
- 自动搜索 Tibo 需要一个 Tavily 免费 API Key；注册不要求信用卡。Token Eyes 不会要求或配置付费套餐。
